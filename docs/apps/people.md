## 4. 使い方（主催者向け）

**対象**：めぐる 人物メモ（`/people`）を使う主催者。今はテスト版で、運営者が開いた人だけが使えます（料金なし）。仕様は specs/people/001-people-memo。

人物メモは、イベントのアンケート（GoogleフォームのCSV）から、会った人の一覧を作るアプリです。次の会に誘う人を選び、声をかけた記録を残せます。

### 4-1. アンケートを取り込む

1. Googleフォームの回答を、CSVで書き出します（「回答」→ スプレッドシート → 「ファイル」→「ダウンロード」→「CSV」）。
2. 人物メモの「取り込み」を開き、CSVを選びます。ファイルは画面の中で読むだけで、そのまま送ったり残したりはしません。
3. どのイベントの回答かを選びます。まだなければ、その場で作れます（名前・開催日・自分の会か）。
4. 列の対応を確かめます。LINE名の列は必ず選んでください。一度選んだ対応は覚えるので、次から同じ質問文は自動で当たります。
5. 同じ人の候補が出たら、1行ずつ「つなぐ」か「別の人」を選びます。勝手にはつなぎません。
6. 「取り込む」を押すと、人の一覧ができます。間違えたときは、イベントのページから取り込みを取り消せます。

- 同じCSVをもう一度取り込んでも、もう取り込んだ行は入りません。
- 「個別の案内は希望しない」を選んだ人は、誘う候補に出ません（人の一覧には出ます）。

### 4-2. 人を探して思い出す

- 「人」で、名前・LINE名・メモから探せます。ひらがなとカタカナ、全角と半角は区別しません。
- 来たイベント・次回参加・欲しいつながり・キャリアの興味・最後に会った日で絞れます。答えは、いちばん新しい回答で比べます。
- 人のページには、来たイベントとそのときの答え、別名（前のLINE名）、メモ（見た目の特徴・話したこと）、同意が1ページで出ます。
- アンケートのない会で会った人は、「人を足す」で手で足せます。そのときの同意は、主催者が選びます。
- 同じ人が2人に分かれていたら「この人と同じ人」でまとめ、間違ってつないだ回答は「別の人に分ける」で分けられます。

### 4-3. 次の会に誘う

1. 「誘う候補」を開きます。初めは、今日以降でいちばん近い自分の会が「誘う会」に選ばれています。
2. 出るのは、交流会・勉強会の案内に同意した人だけです。「前に来た」「次回参加」などで絞れます。
3. 「文をコピー」で誘いの文をコピーし、LINEなどで送ります。文の型は「誘いの文と目標」で変えられます（差し込み：{名前}・{会の名前}・{日にち}）。
4. 送ったら「興味を聞いたにする」を押し、進み具合（興味を聞いた・参加リンクを送った・来た）を残します。誘った会の回答を取り込むと、自動で「来た」になります。

- 上の段に、リピーター（自分の会に2回以上来た人）の数と目標が出ます。目標は「誘いの文と目標」で決めます。
- 自分の会のページに、参加者・初めて・前にも来た人の数が出ます。

### 4-3b. 声かけリストとして使う（specs/people/002）

- **今日の声かけ**：誘う候補の上に「過ぎたもの・今日やること・近い誕生日」が出ます。人のページで「次にやること」（日付と内容）を決めると、その日に出ます。終わったら「終わった」を押し、連絡の記録に残すかを選びます。
- **タグ**：人のページで「常連」「登壇してくれそう」などのタグを付け、人の一覧と誘う候補で絞れます。名前を直す・消すのは「誘いの文と目標」の画面から。
- **来てくれそう度**：人ごとに高・中・低を付け、誘う候補を来てくれそう度の順に並べたり、絞ったりできます。
- **並べ方とまとめ方**：人の一覧で、最後に会った順・初めて会った順・更新順・あいうえお順・来てくれそう度順と、年月ごと・タグごと・あいうえおの行ごとのまとめ方を選べます。選んだものは覚えます（どの端末でも同じ）。
- **連絡の記録**：いつ・何で（LINE・会場で・そのほか）・何を話したかを、人のページに日付つきで残せます。探す欄で記録の言葉からも探せます。
- **会ごとの声かけの一覧**：自分の会のページの「声かけの一覧」で、興味を聞いた・参加リンクを送った・来た の人数と人が並びます。そこから進み具合を変えられます。
- **自由な項目と SNS のリンク**：「好きなもの」などの項目を足して人ごとに値を入れられます。Instagram・X・Facebook のプロフィールの URL を入れると、開くボタンが出ます。
- **書き出す**：人の一覧の「書き出す」で、今の絞り込みに合う人を CSV（Excel で開ける）で保存できます。消した人は入りません。

### 4-4. 仕事の相談先へのつなぎ

- 誘う候補の上で「仕事の相談先へのつなぎ」に切り替えると、転職・求人情報か副業・業務委託案件の案内に同意した人だけが出ます。
- **本人に聞いて、OKをもらってからつなぎます。** 「声かけを始める」で相談先の名前を入れ、「本人に聞いた → OKをもらった → つないだ」を残します。OKの前に「つないだ」にはできません。
- 人物メモは記録だけを残します。相手の情報を、ほかの人やサービスへ自動で送ることはありません。

### 4-5. 記録を消す

- 参加者から「自分の記録を消してほしい」と言われたら、その人のページの「この人を消す」から、名前を入れて消します。回答・メモ・同意の記録・声かけがすべて消え、会ごとの参加者数だけが数として残ります。元には戻せません。
- 同じCSVをもう一度取り込んでも、消した人の回答は入りません。
- めぐるを退会すると、人物メモのデータもすべて消えます。

### 4-6. 個人の情報の扱い

- 取り込んだ名前・答え・メモは、人物メモの中だけに置きます。ブラウザの保存（あとで開くための記録）や、ログには残しません。
- 探す言葉と絞り込みは、画面のURLやブラウザの履歴に入れません。
