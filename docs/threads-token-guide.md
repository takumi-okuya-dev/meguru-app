# 自分のMetaアプリのトークンでのアカウント追加（運営者向け）

利用者が自分のMetaアプリで作った長期トークンを貼り付けて、Threadsアカウントを追加する機能（[specs/010-token-account-add](../specs/010-token-account-add/spec.md)）の、運営者向けの説明です。利用者向けの手順は、アプリの公開ページ`/guide/threads-token`にあります。

024（2026-11-08）から、審査の前のふだんのつなぎ方は、テスター招待のあと「Threadsで許可する」です（[external-services-setup.md](external-services-setup.md) 9-8「テスター招待の運用」）。トークンの貼り付けは、自分のMetaアプリを持つ人向けの別の入口として残します。運営者がトークンを作って利用者に渡す運用はしません。

## 画面の手順の元

利用者に見せる手順は、次の2か所にあります。Metaの開発者サイトの画面の名前が変わったら、両方を直してください。

| 場所 | ファイル | 中身 |
|---|---|---|
| 追加の画面の短い手順（5つ） | `apps/web/src/apps/threads/components/connect/TokenConnectForm.tsx`の`TOKEN_STEPS` | アプリを作る → 権限を加える → テスターに加える → ユーザートークン生成ツール → 貼り付ける |
| 詳しい手順のページ | `apps/web/src/apps/threads/pages/guide-threads-token.tsx` | 6つの手順と、それぞれの「この手順の目的」、取り消し方、うまくいかないとき |

手順は「何をする手順か（目的）」を必ず書き、画面の写真は使いません。Metaの画面が変わっても、目的から利用者が探せるようにするためです。直したら、ページの最後の日付（「この手順は○年○月○日時点の内容です」）も新しくします。

## 必要な権限

| 権限 | 使うところ | ないとき |
|---|---|---|
| `threads_basic` | プロフィールの取得（追加に必須） | 追加できない（「トークンを確かめられませんでした」） |
| `threads_content_publish` | 自動投稿（005） | 追加はでき、「投稿の権限がありません」と案内。自動投稿は「投稿できない」状態 |
| `threads_manage_insights` | 反応数・フォロワー数（006） | 追加はでき、「反応数を読む権限がありません」と案内 |
| `threads_manage_replies` | 時間差のメンションの返信（023） | 追加はでき、このアカウントの設定の「時間差のメンション」に注意の帯を出す。メンションの返信は出せない |

## しくみの要点

- 貼り付けたトークンは、そのトークン自身で`debug_token`を呼んで、期限・発行の時刻・権限を読みます（同じアプリのトークンどうしなら調べられるため）。読めないときは60日とみなし、2時間後に確かめ直します（[research.md R3・R8](../specs/010-token-account-add/research.md)）。
- 期限の延長は、このアプリの接続と同じ日次の処理で行います。延長（`refresh_access_token`）にアプリのシークレットは要りません。
- ThreadsのユーザーIDはMetaアプリごとに違うことがあるため、二重登録はユーザーIDとユーザー名の両方で照合します（[research.md R6](../specs/010-token-account-add/research.md)）。
- 利用者のMetaアプリのアンインストール・データ削除の通知は、このアプリには届きません。トークンが使えなくなったことは、次にThreadsへ問い合わせたときの認証のエラーで知り、要再接続にします。
- 確認に10分の間に5回失敗した利用者は、10分待ちになります（他人のトークンの総当たりを防ぐため）。

## Metaの規約

Meta の Platform Terms では、このアプリは、トークンでの接続の利用者（Metaアプリの持ち主）のサービスプロバイダーとして、その利用者のためだけにデータを処理する形になります。利用規約（`apps/web/src/shell/pages/terms.tsx`）の「トークンでの接続の扱い」にこのことを書いています。公開の前に、運営者が文面を確かめ、運営者の名前・連絡先を書き足してください（法的な確認は別に行う）。

## debug_token の応答の形

実際のMetaアプリのトークンで確かめた結果は、[research.md R3](../specs/010-token-account-add/research.md)の末尾に書きます（tasks.md T047）。
