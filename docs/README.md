# 文書の一覧

このリポジトリの文書が、どこに何を書いているかの一覧。**迷ったら、ここから探す**。文書を足す・消す・役目を変えたときは、同じPRでこの一覧も直す。

- 個々の機能の仕様・計画・タスクは`specs/`に置く（2026-11-12からは`specs/<アプリ>/NNN-…`。`specs/001`〜`028`はそのまま）。ここには載せない。
- 同じことを2つの文書に書かない。書くなら片方を「正本」にして、もう片方はリンクと1行の要約だけにする（正本の列）。

## 1. まず読むもの

| 文書 | 何が書いてあるか | 読む人 |
|---|---|---|
| [README](../README.md) | リポジトリの入口。めぐるとは何か・ブランチとデプロイ・開発環境の用意・テスト・運営者用のスクリプト | 開発者・AI |
