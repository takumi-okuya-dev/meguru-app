# ThreadsGrower App

Threadsアカウントを「投稿ストック→承認→自動投稿→分析→改善」のループで育てるためのアプリ。

- 由来: Obsidian vault `Wiki/仕事/システム開発/アイデア/Threads自動投稿アプリ.md`
- 既存の [threads-grower](https://github.com/MarronTaku/threads-grower) リポジトリ（spec-kit 導入済み・実装進行中）とは**別プロジェクト**として並走する（2026-10-01、ユーザー確認済み）。
- 開発方法論: [BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD) を導入し、アイデア→PRD/設計の叩き台を作成したのち、ユーザーレビュー → MVP実装（[spec-kit](https://github.com/github/spec-kit) 導入）という順で進める。
