# 確かめの手順（quickstart）：セルフ受付

**前提**：001 の quickstart.md 1・2 が通ること（イベント・名簿・受付・手伝う人）。手元は `pnpm dev`、テスト版はステージング。

## 1. 主催者がセルフ受付のQRを出す

1. 名簿に3人（松本 れい・井上 そら・木村 ゆうき）と、0円の区分の人（招待）を入れる。
2. 「セルフ受付」で「セルフ受付のQRを出す」。QR・リンク・期限が出る。

## 2. 参加者が自分で受付する

1. 別のスマートフォン（ログインなし）でQRを開く。イベントの名前・日時・会場だけが出る。
2. 「まつもと れい」と入れる → 「No.1 松本 れい さん・通常 3,000円」が出る。ほかの人の名前は出ない。
3. 「PayPay」を選ぶ → QRと3,000円が出る。主催者の受付の画面の上に、5秒以内に「確かめ待ち：No.1 松本 れい・PayPay 3,000円」が出る。PayPayの合計は増えない。
4. 主催者が「受け取った」を押す → 支払い済み・PayPayの合計が増える。参加者の画面も「受付が済みました」になる。
5. 名簿にない名前で探す → 「見つかりませんでした」。似た名前の候補は出ない。
6. 0円の区分の人で探す → 払い方を選ばずに「来場を記録しました」。

## 3. 飛び入りの申し出

1. 参加者の画面で「飛び入りとして申し出る」→ 名前を送る → 「受付の人が確かめています」。
2. 受付の画面に「申し出」が出る → 「名簿に入れる」→ 参加者の画面が受付番号と払い方の選択に進む。

## 4. 守り

1. 受付済みの人でもう一度探して申告する → 「もう受付済みです（No.1）」。
2. 主催者がセルフ受付を止める → 参加者の画面が5秒以内に「受付の人に声をかけてください」になる。
3. 締めの画面で、確かめ待ちが残っていれば知らせが出る。
