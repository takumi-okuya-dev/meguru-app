# 媒体の決まり：外部媒体展開

**日付**：2026-11-04 | **計画**：[../plan.md](../plan.md) | **出どころ**：港の管理画面「外部媒体展開」（2026-11-04に読んだ内容。research.md R11）

`packages/shared/src/media/<媒体>.ts` に、この表のとおり持つ。記号：**必**＝必須、**固**＝登録後に変えられない、**既**＝媒体の既定値（`media_defaults`）で入れられる、`E.` はイベントの情報（data-model.md）、`P.` は宣伝内容。

## 共通

- 選ぶ欄は、媒体の選択肢をすべて出し、選んだ値に「このイベントでは『〇〇』を選びます」と理由を添える（spec FR-011）。
- 開始・終了は `YYYY-MM-DD` と `HH:mm` に分ける（媒体の画面に合わせる）。`E.endAt` がなければ空にし、黄「終了の日時がありません。決めて入れてください」。
- 金額は数字だけ。`E.feeYen` がなければ空にし、黄。
- 自動の直し（research.md R4）の共通の行：URL（`https?://`・`maps.app.goo.gl` など）・LINE（`LINE`・`line.me`・`@` から始まるID）・メールアドレス・電話番号・口座・PayPay。媒体ごとに、どれを外すかを下に書く。
- 作業のSTEPの最初は「ルールの確認」、最後は「公開する」（spec FR-030）。最後のSTEPの共通の文：「公開したら、入力の画面の『掲載URL』にURLを保存し、状況を『掲載済み』にしてください。」
- 画像のプロンプトの共通：イベントの情報（名前・日時・場所・対象者・参加費）を本文に入れる（URLを読ませない。宣伝内容のURLは任意のため）。見出しは2行・1行6文字以内、色は3色まで、バッジは3つまで（初参加歓迎・一人参加OK・エリア名のうち、宣伝内容に根拠のあるもの）。画像に入れないもの：URL・QRコード・連絡先・他のサイトやSNSの名前・口座。イラスト型と写真を使う型（写真を添えたときだけ）。
