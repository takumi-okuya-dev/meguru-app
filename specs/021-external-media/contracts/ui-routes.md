# 画面の取り決め：外部媒体展開

**日付**：2026-11-04 | **計画**：[../plan.md](../plan.md) | **モック**：https://claude.ai/artifact/78VBSVeE19t3EqqvjckMRZ

画面は少し複雑なので、まずモックのとおりに作り、テスト版で使いながらシンプルにする（spec Clarifications）。

## 1. サイドバー

「戦略」の見出しの下に、課題・宣伝内容・**外部媒体展開**・リサーチの順。戦略が使えない人には出さない（019）。見せてもらっている人の画面（`/teams/:teamId/accounts/:accountId`）には出さない。

## 2. 外部媒体展開 `/accounts/:accountId/external-media`

- 上部バー「外部媒体展開」。
- 「イベント」の選ぶ欄：宣伝内容のうち開催日時のあるもの。選択肢の文は「11/25(水) タイトル　［掲載済み：Peatix・YOUTRUST］」。下に「宣伝内容のうち、イベントの情報（開催日時）があるものを選べます」。1つもなければ「宣伝内容に、イベントの情報を入れると使えます」と宣伝内容へのリンク。
- 「媒体」の一覧（5行）：媒体名・一言の説明・状況の印（未着手＝灰、作成中＝注意の色、掲載済み＝成功の色、掲載停止＝灰の点線）・ボタン（まだ作っていなければ「掲載内容を作る」、作っていれば「開く」。どちらもoutline）。
- 閉じたトグル「媒体の既定値」：媒体ごとに `defaultable` の欄を並べ、保存（`canEdit` のときだけ）。

## 3. 入力の画面 `/accounts/:accountId/external-media/:promotionId/:media`

- 上部バー：戻る・媒体名・「保存」（`canEdit`。直していなければ押せない）。
- 状況の選ぶ欄と、掲載URLの入力。
- ボタンの行：「作業を始める」（primary。`?view=work` へ）・「AIと整える」（outline）・「まとめてコピー」（outline）・「作り直す」（ghost。確かめてから。FR-052）。
- `sourceChanged` なら、注意の帯「宣伝内容が変わりました」と「作り直す」。
- 「ルールのチェック」の枠：赤（`destructive` の薄い地）・黄（`warning`）・参考（灰）の件数と、項目の一覧。閉じたトグル「自動で直した内容（n件）」：欄・外した行の書き出し・理由。
- 2列（パソコン）／1列（スマートフォン）：
  - 左：「宣伝内容（変わりません）」の読むだけの枠（タイトル・イベントの情報・宣伝したい内容）。スマートフォンでは閉じたトグル。
  - 右：媒体の区切り（ステップ）ごとの見出し（青の文字）と、欄のカード。カードには、欄の名前・必須（赤の小さな文字）・登録後に変えられない・文字数／上限・「コピー」・入力・媒体の画面での欄の名前と説明（灰色の小さな文字）・選ぶ欄は選択肢の丸いチップと「このイベントでは『〇〇』を選びます」・タイトルはほかの案。
  - 最後に画像の枠：大きさと注意の1行・画像の種類のチップ（イラスト／写真を使う）・「画像のプロンプトをコピー」。
- 「AIと整える」：`FormDialogFrame`。「プロンプトをコピーする」→ 答えを貼る → タイトル・本文の候補 → 「反映する」（018の `SparringDialog` と同じ流れ）。
- まだ作っていない媒体を開いたときは、欄の代わりに「掲載内容を作る」だけを出す。

## 4. 作業の画面 `…?view=work`

- 上部バー：戻る（入力の画面へ）・「〇〇に載せる」。保存も状況の変更もしない（FR-031）。
- 「上から順番にコピーして、〇〇に貼り付けてください。」
- STEPのカード：「STEP n」（青の小さな文字）・見出し・媒体の画面で何をするかの1行（灰色）・値の行（欄の名前・必須・値・「コピー」（primary））。画像のSTEPは「画像のプロンプトをコピー」。最初のSTEP（ルールの確認）は青の枠で、赤・黄の件数を出す。
- 最後のSTEP「公開する」：公開後に掲載URLを保存して状況を「掲載済み」にする案内と、媒体ごとの決まり。

## 5. 宣伝内容の編集（`PromotionFormDialog` を変える）

- 今の欄の下に、閉じた区分「イベントの情報（任意）」と「入れると、外部媒体展開と宣伝投稿に使えます」。
- 開くと：開始・終了（2列）・会場／オンラインのチップ・会場名・都道府県（選ぶ）・市区町村・番地・建物・最寄り駅・定員・参加費（円）（2列）・参加費の説明・キャンセルの決まり・対象者・主催者名。下に「申込先のURLは、上の『専用URL』を使います」。
- イベントの情報の中身があるときは、最初から開いておく。

## 6. 共通

- 「コピー」は、今の `SwapLabel` を使う小さな部品 `CopyValueButton`（新規）にする。押すと「コピーしました」に変わり、ボタンの位置は動かさない（docs/ui-design.md §6）。
- スマートフォンで横にスクロールさせない（FR-063）。
- 保存がぶつかったら（`STALE_UPDATE`）、002・018と同じく、上書きするか最新の内容を読み直すかを選ばせる（FR-064）。
- 戦略が使えないときは `FeatureUnavailable`、見せてもらっている人が開いたら「この画面は、オーナーと担当の人だけが使えます」。
