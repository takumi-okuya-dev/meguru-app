# Quickstart：外部媒体展開

**Feature**：[spec.md](./spec.md) | **計画**：[plan.md](./plan.md)

## 1. 自動のテスト

```bash
pnpm --filter ./packages/shared test -- media
pnpm --filter ./apps/api test -- external-media migration-0019 promotions prompt
pnpm --filter ./apps/web test -- external-media promotions
pnpm --filter ./packages/shared test && pnpm --filter ./apps/api test && pnpm --filter ./apps/web test && pnpm lint && pnpm -r exec tsc --noEmit
```

確かめること：
- **shared（媒体の決まり）**：5つの媒体それぞれで、
  - 欄の並び・区切り・必須・上限が contracts/media.md と同じ
  - 港のIT交流会と同じ材料（開催日時・会場・定員25・参加費5,000円・地図のURL・LINEの案内・紹介割引を含む本文）から、選ぶ欄の値と理由が決まる（例：こくちーず＝オフライン・有料・人脈／交流会）
  - 自動の直し：つなげーとで地図のURL・紹介割引・LINEの行が外れて理由が残る。こくちーずプロは外さない（SC-003）
  - ルールのチェック：終了がないと黄、Peatixのイベント名が45文字を超えると赤、YOUTRUSTの住所が空なら黄
  - 作業のSTEPの数（15・10・9・8・12）と、最初・最後のSTEP
  - 画像のプロンプトに、大きさ・入れてはいけないものが入る
  - 「AIと整える」の答えの読み取り（目印あり・なし・片方だけ）
- **API**：
  - 宣伝内容の `event` の保存・NULL・省略（今の値のまま）
  - 宣伝投稿のプロンプト：event があるときだけ1行が増え、ないときは今と同じ文
  - 外部媒体展開：作る（状況が作成中に）・保存（禁止の行を貼ると外れる）・状況と掲載URL・衝突（STALE_UPDATE）・作り直し・宣伝内容が変わると `sourceChanged`
  - 宣伝内容を直しても掲載内容は変わらず、掲載内容を直しても宣伝内容は1文字も変わらない（SC-004）
  - 守り：見せてもらっている人は ROLE_FORBIDDEN、関わりのない人は 404、戦略がOFFは FEATURE_DISABLED（SC-005）、決済で読むだけは書けない
  - マイグレーション（足すだけ・宣伝内容の削除で消える）
- **Web**：サイドバーの「外部媒体展開」、一覧と状況の印、入力の画面（欄・コピー・ルールのチェック・自動で直した内容・画像のプロンプト）、作業の画面（STEP・保存しない）、AIと整える、宣伝内容の「イベントの情報」

## 2. 手元で試す

1. 宣伝内容を1件開き、「イベントの情報」に開始・会場・定員・参加費・キャンセルの決まりを入れて保存する。
2. サイドバーの「戦略 › 外部媒体展開」でそのイベントを選び、Peatixの「掲載内容を作る」を押す。Peatixの5ステップの順に欄が並ぶ。
3. 本文に地図のURLを足して保存する。URLの行が外れ、「自動で直した内容」に残る。宣伝内容の本文は変わらない。
4. 「作業を始める」で作業の画面にし、STEPのコピーで値がコピーされることを確かめる。保存も状況の変更も起きない。
5. 状況を「掲載済み」にし、掲載URLを入れて保存する。一覧の選択肢に「掲載済み：Peatix」が出る。
6. 「AIと整える」でプロンプトをコピーし、ChatGPTの答えを貼って、タイトル・本文の候補が出ることを確かめる。
7. スマートフォンの幅（390px）で、入力の画面と作業の画面が横にスクロールせずに使えることを確かめる。

## 3. テスト版で確かめる（マージのあと）

港のイベント1件で、5つの媒体それぞれに、作業の画面だけを見ながら実際に登録してみる（SC-002）。媒体の画面と欄の名前・並び・選択肢が合っているか、使いにくいところはどこかを記録し、シンプルにする次の直しに使う。
