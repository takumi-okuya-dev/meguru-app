# 画面の契約：運営者がすべてのアカウントを接続方法ごとに確かめられる一覧

**日付**：2026-11-09 | **計画**：[../plan.md](../plan.md) | **モック**：[026 アカウント一覧 モック](https://claude.ai/artifact/BgQqyj6fDtY6KeNYYFQm4W)

- **見た目**：「テスター招待」（024）の下線のタブ・行の枠・文字の大きさにそろえる。新しい強調の色や形は使わない。
- **出す相手**：運営者だけ（`settingsGroupsFor(operator)`）。
- **文言**：表示名は`packages/shared/src/operator-accounts.ts`から出す。

## 1. 置き場所（`/settings/operator-accounts`）

- 設定の「運営」の中で、「テスター招待」の次、「上限」の前に「アカウント一覧」（`ListIcon`）を足す。
- 運営者でない人がURLを開いたときは、今の運営の区分と同じ扱いにする（区分を出さない。APIは`403 OPERATOR_ONLY`で、画面には「この画面は運営者だけが使えます。」）。

## 2. 画面の中身（上から）

1. 見出し「アカウント一覧」と、1行の説明「すべてのアカウントと、Threadsへのつなぎ方です。見るだけで、ここからは変えられません。」
2. 検索欄（ラベル「アカウント・@ユーザー名・オーナーで探す」、`type="search"`）。入力が止まって300ミリ秒後に読み込む。
3. 接続方法の下線のタブ：「すべて {all}」「Threadsで許可する {app}」「トークン {token}」「つなぐ前 {none}」。初めは「すべて」。狭い幅では折り返す。
4. 一覧（枠つき）：
   - **`md`以上**：5列の表。見出しの行「アカウント・接続方法・状態・オーナー・テスター招待」。
     - アカウント：名前（太字）と、その下に@ユーザー名（つなぐ前は「未接続」）
     - 接続方法・状態：表示名
     - オーナー：名前（なければ「名前なし」）と持っているアカウントの数（「山田 太郎（2件）」）、その下にメールアドレス（オーナーがいなければ「—」）
     - テスター招待：表示名（なければ「—」）
   - **それより狭いとき**：1行を段に分ける。
     - 1段目：名前（太字）と、右に状態
     - 2段目：「@ユーザー名・接続方法」（つなぐ前は「未接続・つなぐ前」）
     - 3段目：「オーナー：名前（2件）・メールアドレス」
     - 4段目：「テスター招待：表示名」（あるときだけ）
5. 続きがあれば「もっと見る」（枠線のボタン）。押すと次の50件を下に足す。
6. 下に1行「作った日の新しい順。テスター招待の操作は「テスター招待」で行います。」

## 3. 状態ごとの表示

| 状態 | 表示 |
|---|---|
| 読み込み中 | 「読み込み中…」 |
| 読めない | エラーの文（`describeError`） |
| 行がない（検索なし） | 「ありません」 |
| 行がない（検索あり） | 「ありません」 |
| 「もっと見る」の読み込みが失敗 | 一覧は残し、ボタンの下にエラーの文 |

- タブや検索語を変えたら、一覧は先頭から読み直す。
- 件数は、検索しても変わらない。
