# 画面の契約：テスター招待での接続、アカウント数・投稿数の上限、無料体験の廃止

**日付**：2026-11-08 | **計画**：[../plan.md](../plan.md) | **モック**：[024 テスター招待と上限 モック](https://claude.ai/artifact/R6Pc9o8YomNZNDEB161eSf)

**見た目の決まり**：今の画面に合わせ、新しい強調の色や形は足さない（docs/ui-design.md）。
- 主な操作：黒の塗りの丸いボタン
- それ以外の操作：枠線か、枠なしのボタン
- カード：角の丸い枠

**文言**：短くし、手順は箇条書きにする。スマートフォンの幅（390px）で使えるようにする。

## 1. 契約前の画面（新規・`SubscribeRequired`）

- **出すとき**：`me.billing.state === "unsubscribed"`のとき、または`SUBSCRIPTION_REQUIRED`を受け取ったとき。サイドバーとアプリの中の画面に替えて出す（`guards.tsx`。016の`TestAccessRequired`と同じ出し方）。
- **中身**（モック1枚目）：
  - 見出し「契約してから使い始めます」
  - 料金のカード「アカウント1件につき　月1,000円」
  - 「契約する」（Checkoutへ）
  - 箇条書き「契約すると、すぐにアカウントを作れます」「いつでも解約できます」
  - 下に離して「ログアウト」「退会する」
- **Checkoutから戻ったとき**：今の`/billing/sync`のとおり状態を読み直し、ホームへ移る。取りやめて戻ったら、この画面のまま。
- **`/settings/billing`は開ける**（料金と「契約する」の表示）。

## 2. つなぐ画面（変える・`ConnectMethods`）

- **出し分け**：`me.testerInvites.enabled`が true で、`app`を出しているとき、「Threadsで許可する」の場所に`TesterApplicationPanel`を出す。
- **トークンでつなぐ方法**：今のまま、閉じた形で下に置く。
- **招待の管理がOFFなら**：今の画面のまま。

| 申し込みの状態 | 出すもの（モック） |
|---|---|
| なし・取り下げ | 「Threadsのユーザー名」の入力欄（`@username`）、説明「運営者がテスターに招待したあと、つなげます。」、「招待を申し込む」（黒の塗り）（2枚目） |
| 申し込み中 | カード：「申し込み中」・`@ユーザー名`・「運営者の招待をお待ちください。」・「申し込みを取り消す」（枠なし）（3枚目） |
| 招待済み | カード：「招待済み」・`@ユーザー名`・承認の手順（次の3つ）、その下に「Threadsで許可する」（黒の塗り）と、小さな注意「つなげなかったときは、招待を承認してから、もう一度お試しください。」、いちばん下に「申し込みを取り消す」（枠なし）（4枚目）<ol><li>Threadsのアプリで、設定 › アカウント › ウェブサイトのアクセス許可 › 招待 を開く</li><li>招待を承認する</li><li>下の「Threadsで許可する」を押す</li></ol> |
| 見送り | カード：「今回は招待を見送りました」と理由（あれば）、ユーザー名の入力欄（前の値を入れておく）と「もう一度申し込む」 |

**エラーの出し方**：
- 形の違うユーザー名：入力欄の下に「Threadsのユーザー名を確かめてください」。
- `RATE_LIMITED`：「少し時間をおいてから、もう一度お試しください」。

**`/threads/complete`**：
- 対象のアカウントの申し込みが「招待済み」で、`THREADS_AUTH_CANCELLED`・`THREADS_AUTH_FAILED`で戻ったとき：エラーの代わりに、つなぐ画面に戻して承認の手順と「招待を承認してから、もう一度お試しください」を出す（research.md R13）。

## 3. アカウントを作る（変える・`account-new`）

- **上限に達しているとき**（`me.limits`の`ownedAccountCount >= accountLimit`）：注意のカード「作れるアカウントは◯件までです」「増やしたいときは運営者に連絡してください。」を出し、入力欄と「作る」は押せなくする（モック7枚目）。
- **無料体験の文言**：「無料体験中は1件まで」「2件目から月500円」は、前からの無料体験の人（`state === "trial"`）だけに出す。月500円の文言はなくす。

## 4. 投稿のスケジュール（変える・`PostingScheduleDialog`）

- 見出しの横に「◯件まで」（オーナーの1日の投稿数の上限）を出す。
- **上限に達しているとき**：「時刻を足す」を押せなくし、「1日に投稿できるのは◯件までです。」と出す。
- **登録した時刻が上限を超えているとき**（`overLimit`）：
  - 注意「上限が◯件に下がったため、◯つ目からの時刻には投稿しません。」を出す。
  - 上限を超えた時刻（早い順で数えて上限より後のもの）を薄くし、「投稿しません」と付ける（モック8枚目）。
- 時刻を消すのは今のとおりできる。

## 5. 運営 › テスター招待（新規・`/settings/tester-invites`）

- **置き場所**：設定の「運営」の区分に足す（`OPERATOR_SETTINGS_GROUP`）。運営者にだけ出す。
- **中身**（モック5枚目）：
  - **上**：
    - 「テスター枠　使用 / 枠」と「枠の数を変える」（ダイアログで数を入れる）
    - 「Metaでテスターを加える」（Metaの開発者の画面を新しいタブで開くリンク。一覧の応答の`threadsAppId`から作り、`null`なら出さない）
  - **タブ**（丸い形、横に流れる）：
    - 「申し込み中 n」「招待済み n」「接続済み n」「外してよい n」
    - 選んだものを黒の塗り、ほかを枠線にする
  - **一覧**：
    - 各行の上に、`@ユーザー名`、申し込んだ人の名前・メールアドレス（退会していれば「退会した利用者」）、申し込んだ日・状態が変わった日
    - 注意（あれば）：「同じユーザー名の申し込みがあります」「すでにつながっています」「別のアカウント（@…）でつながりました」
    - 行の下に、状態に合わせた操作

    | タブ | 操作 |
    |---|---|
    | 申し込み中 | 「招待した」（枠線）・「見送る」（枠なし。理由を入れるダイアログ） |
    | 招待済み | 「申し込み中に戻す」（枠なし） |
    | 接続済み | なし |
    | 外してよい | 理由と「外した」（枠線）。理由の文：`account_deleted`「アカウントが消されました」、`user_withdrawn`「利用者が退会しました」、`withdrawn`「申し込みが取り下げられました」、`token_connected`「トークンでつながりました」、`username_mismatch`「別のアカウント（@…）でつながりました」 |

  - **下**：「見送り・取り下げを見る」（`view=closed`の一覧へ）
- **枠がいっぱいで「招待した」を押したとき**：確認のダイアログ「テスター枠がいっぱいです（25 / 25）。Metaの枠に空きがあるときだけ続けてください。」と「続ける」「やめる」。
- **招待の管理がOFFの環境**：上に「この環境では招待の管理を使っていません」を出し、一覧は読むだけ（操作のボタンを出さない）。

## 6. 運営 › 上限（新規・`/settings/limits`）

- **置き場所**：設定の「運営」の区分に足す。
- **中身**（モック6枚目）：
  - **全員の既定値**：「アカウントの数　[3] 件」「1日の投稿数（1アカウント）　[10] 件」と「保存」（枠線）
  - **人ごとの上限**：
    - メールアドレスの欄と「探す」（019の「使える機能」と同じ形）
    - 見つかった人のカード（名前・メールアドレス・今のアカウントの数）に、2つの数の欄
    - 各欄の下に「この人だけ」か「既定値」を出す
    - 「保存」（枠線）と「既定値に戻す」（枠なし）
    - 運営者なら「運営者には上限をかけません」と出す
  - **既定値と違う人**：一覧（名前・「アカウント5件・投稿は既定値」の形）と、行ごとの「既定値に戻す」
  - **記録**：閉じたトグル「変更の記録」。開くと50件
  - **下**：「運営者には上限をかけません。」

## 7. 料金と無料体験の文言（変える）

| 画面 | 変えること |
|---|---|
| ランディング（`landing.tsx`） | 「1か月無料」などをなくし、「アカウント1件につき月1,000円」にする |
| 利用規約（`terms.tsx`）・特定商取引法に基づく表記（`legal-commerce.tsx`） | 無料体験の条項をなくし、料金を1件1,000円にする。前からの無料体験の人の経過措置を一文で残す |
| 契約と支払い（`settings/billing.tsx`） | 料金の表を1行（1件につき月1,000円）にする。無料体験の表示は前からの人だけ |
| ホーム（`account-home.tsx`）・`TrialEndingBanner` | 無料体験の残りの日数は、前からの人だけ（今のまま） |
| プロンプトのカード・`BillingRequiredDialog` | 「月500円」をなくし、「契約する」の案内にする |

## 8. 関係する画面の決まり

- 「運営」の区分の項目は、使える機能・グループ・テスター招待・上限の順にする。
- 契約前の画面・テスター招待・上限は、ダークモードでも今の色の決まりに従う。
