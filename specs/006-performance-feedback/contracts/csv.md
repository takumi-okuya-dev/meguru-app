# CSVの契約

**対象feature**：[spec.md](../spec.md) FR-028〜FR-030 ／ **調査**：[research.md](../research.md) R7・R9 ／ **分析での使い方**：[docs/threads-algorithm-research.md](../../../docs/threads-algorithm-research.md) 5章

CSVはWebで組み立てる。APIの`GET /performance/export`（[api.md](./api.md)）が返す行を、下の列の順に並べる。

## 形式

- 文字コードはUTF-8で、先頭にBOM（`﻿`）を付ける。
- 改行はCRLF。1行目は列名（日本語）。
- すべての値を`"`で囲み、値の中の`"`は`""`にする（本文の改行・カンマ・引用符を1つのセルに収める）。
- 日時は日本時間で、`2026-09-25T19:01:00+09:00`の形。日付だけの列はない。
- 値がない（取れていない・本featureより前で記録がない）ときは空欄。
- ファイル名：`threads-{username}-posts-{YYYYMMDD}.csv`・`threads-{username}-snapshots-{YYYYMMDD}.csv`（日付は書き出した日、日本時間）。

## 投稿ごと（`kind=posts`）

投稿済みの投稿を1行ずつ、投稿した日時の新しい順。タブの絞り込みにかかわらず全件。

| # | 列名 | 中身 |
|---|---|---|
| 1 | 投稿ID | `post_drafts.id` |
| 2 | 投稿した日時 | `published_at` |
| 3 | 曜日 | 日〜土（日本時間） |
| 4 | 時 | 0〜23（日本時間） |
| 5 | 本文 | |
| 6 | 文字数 | コードポイントの数（絵文字1つは1文字）。003の文字数・DBの`char_length`と同じ数え方 |
| 7〜12 | 閲覧・いいね・返信・リポスト・引用・シェア | 最新（確定していれば確定）の値 |
| 13 | 基準値に対する倍率 | 判定済みのときだけ。小数第3位まで |
| 14 | 判定 | 好調・普通・低調・確定待ち・計測できません・判定なし（確定したが閲覧数がない、または基準値の件数が足りない・0） |
| 15 | 投稿のURL | |
| 16 | 反応数の最終取り込み日時 | |
| 17 | 取り込み時の経過時間 | 最終取り込みの、投稿からの経過（時間・整数・切り捨て） |
| 18 | 値の状態 | 更新中・確定・遅れて確定（確定待ち・計測できませんで値がなければ空欄） |
| 19 | 投稿時点のフォロワー数 | 投稿した日時より前で最も新しいフォロワー数の記録 |
| 20〜25 | 24時間時点の閲覧・いいね・返信・リポスト・引用・シェア | `kind = h24`の履歴（なければ空欄） |
| 26 | バッチID | `draft_batches.id` |
| 27 | バッチの中の順番 | `post_drafts.position + 1` |
| 28 | バッチを登録した日時 | |
| 29 | 承認した日時 | `reviewed_at` |
| 30 | 次に投稿するで前に出したか | はい・いいえ（本featureより前は空欄） |
| 31 | 持ち越されたか | はい・いいえ（同上） |
| 32 | 登録の後に本文を直したか | はい・いいえ・不明 |
| 33 | 予定の時刻の枠 | `HH:MM`（本featureより前は空欄） |
| 34〜37 | バッチ登録時の課題・宣伝内容・リサーチ・投稿ルールの最終更新日時 | `draft_batches`の4列（本featureより前は空欄） |

## 取り込みごと（`kind=snapshots`）

取り込みの履歴を1回につき1行、取り込んだ日時の新しい順。

| # | 列名 | 中身 |
|---|---|---|
| 1 | 投稿ID | 投稿ごとのCSVの投稿IDとつなげられる |
| 2 | 投稿した日時 | |
| 3 | 取り込んだ日時 | |
| 4 | 取り込み時の経過時間 | 時間・整数・切り捨て |
| 5 | 取り込みの種類 | 24時間時点・3日時点・7日時点・遅れて確定 |
| 6 | 取り方 | 時刻の処理・毎日の処理 |
| 7〜12 | 閲覧・いいね・返信・リポスト・引用・シェア | その時点の合計 |
| 13 | その時点のフォロワー数 | 取り込んだ日（日本時間）のフォロワー数の記録 |
