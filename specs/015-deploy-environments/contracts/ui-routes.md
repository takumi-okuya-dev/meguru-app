# 契約：画面（ステージングの帯）

**Feature**：[spec.md](../spec.md) | **UI全体設計**：[docs/ui-design.md](../../../docs/ui-design.md) | **調べ**：[research.md](../research.md) R8

## 1. 環境の帯

| 環境 | 出すか | 文言 |
|---|---|---|
| `production` | 出さない | — |
| `staging` | 出す | 「テスト環境です。本番のデータではありません。ここでの投稿は、つないだThreadsアカウントに実際に投稿されます」 |
| `development` | 出す | 「開発環境です（手元）」 |

- **置き場所**：`AppShell`の`banner`の**いちばん上**（無料体験の終わり・読むだけ・要再接続の帯より上）。ログインの画面・招待の確認・利用規約など、`AppShell`の外の画面にも出す（画面の一番上）。**骨格は1つではない**ので、画面の外枠になるものすべてに置く：`AppShell`・`CenteredLayout`・`SettingsLayout`（2列・スマートフォンの一覧・スマートフォンの中身の3通り）・`TeamSharedAccountPage`・読みもののページの入れ物（`PlainPage`）。
- **出さないところ**：読み込み中（`LoadingSkeleton`）と失敗の画面（`ErrorScreen`）。どちらも一瞬で消えるか、ほかの骨格の中に入れ子で出るので、置くと二重になる。
- **見た目**：注意の色（`warning`）の細い帯。閉じられない（ずっと出す）。
- **スマートフォンの幅**：1行に収まらないときは折り返す。上部バーの操作に重ならない。

**言葉づかい**：画面に出す文言は「テスト環境」、文書（仕様・計画・手順書）では「ステージング」と書く。利用者はブランチの名前を知らないため。

## 2. 検索に載せない

- `staging`のときだけ、`index.html`に`<meta name="robots" content="noindex, nofollow">`を入れる（ビルドのときに差し込む）。
- `production`では入れない。

## 3. 変えないこと

- 今ある帯（無料体験・読むだけ・要再接続）の文言と出す条件は変えない。
- 画面の並び・操作は変えない（帯が1本増えるだけ）。
