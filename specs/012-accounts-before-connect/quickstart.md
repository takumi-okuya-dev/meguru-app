# Quickstart：アカウントを先に作る

**日付**：2026-10-14 | **計画**：[plan.md](./plan.md)

本featureが動くことを確かめる手順。準備は001〜011と同じ（[README](../../README.md)、OrbStackで`orb start`と`docker compose up -d --wait`）。

## 1. 自動のテスト

```bash
pnpm --filter api db:migrate   # 0013_accounts_before_connect（未接続の状態・名前の列）
pnpm lint && pnpm typecheck
pnpm test                      # 共通・Web・API
pnpm e2e -- onboarding         # 名前で作る → 戦略 → 案の登録 → 承認 → 設定でつなぐ
pnpm e2e -- token              # トークンでつなぐ・接続し直す（010の流れ）
pnpm e2e -- team               # 未接続のアカウントは入れない（011の流れ）
```

確かめること（対応するテストはtasks.md）：

| 確かめること | 出どころ |
|---|---|
| 名前だけでアカウントを作れる。上限に達していれば作れず、同時に作っても上限を超えない | FR-002・FR-004、research.md R3 |
| 未接続のアカウントで、戦略・プロンプト・案の一括登録・承認・NGワード・投稿のルールが、接続中と同じに通る | FR-031、SC-002 |
| 未接続のアカウントから、Threadsへの問い合わせ・投稿が1回も起きない（毎日の処理・自動投稿・画面を開いたとき・投稿の権限の確認） | SC-005、research.md R5 |
| 自動投稿をオンにする保存が`THREADS_NOT_READY`（`not_connected`）で拒まれ、オフのままの時刻の保存は通る | FR-032 |
| つないだ前後で、戦略・投稿ストック・設定・操作の記録の件数が同じ。つないだ後も自動投稿はオフのまま | SC-003、FR-013・FR-014 |
| 同じThreadsアカウントに2つのアカウントがつながらない：自分の別のアカウント（`ACCOUNT_ALREADY_REGISTERED`）・他の利用者（`THREADS_ACCOUNT_TAKEN`）を、このアプリの接続とトークンのそれぞれで | SC-004、FR-020〜FR-022 |
| 同じ未接続のアカウントへの同時のつなぐ操作で、後の方が`ACCOUNT_ALREADY_CONNECTED` | FR-018 |
| オーナー以外は、つなぐ・名前を直す・削除ができない | FR-015、FR-040 |
| 未接続のアカウントは、チームを作る・入る・足すのどれでも`ACCOUNT_NOT_CONNECTED`。招待の確認が`needs_connection`になる | FR-050〜FR-052 |
| マイグレーションの前後で、今のアカウントの状態とデータの件数が同じで、名前が表示名（なければユーザー名）で埋まる | FR-044、data-model.md |
| すべての画面で、未接続のアカウントが「未接続」とアカウントの名前で出る（`@null`・`@undefined`・空の名前が出ない） | SC-006 |
| 接続中のアカウントだけの人の画面が、名前の区分と「アカウントを作る」の文言を除いて変わらない | SC-007 |

## 2. 手で確かめる

1. **はじめての人（SC-001・SC-002）**：新しいGoogleアカウントでログインし、「アカウントを作る」で名前を入れて作る（1分以内）。ホームに未接続の帯が出る。課題を入れ、プロンプトを作り、外のLLMの案を貼り付けて承認する。ホームの「次にやること」が「Threadsにつないで自動投稿を始めましょう」になる。
2. **トークンでつなぐ**：「Threadsにつなぐ」から設定の「Threadsとの接続」を開き、トークンを貼り付ける。「つながりました」と「自動投稿を始める」が出る。切り替えメニューの主の名前は、つなぐ前と同じ。自動投稿はオフのまま。
3. **このアプリで許可**（テスターのアカウント）：もう1つアカウントを作り、「Threadsで許可する」でつなぐ。許可の画面から戻ると、設定の画面に「つながりました」が出る。
4. **二重の登録**：3つ目のアカウントを作り、2.と同じThreadsアカウントのトークンでつなごうとする。「@…は、あなたのアカウント『…』につながっています」とリンクが出て、3つ目は未接続のまま残る。
5. **パフォーマンスと自動投稿**：未接続のアカウントで、パフォーマンスの画面と投稿の時刻の区分に「Threadsにつなぐと使えます」が出て、オンにできない。
6. **チーム**：未接続のアカウントだけを持つ人で招待リンクを開き、つなぐ案内が出る。つないだ後に招待の画面へ戻り、参加できる。
7. **削除**：未接続のアカウントを、名前を入れて削除する。トークンの注意が出ない。
