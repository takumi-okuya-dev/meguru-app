# 画面の取り決め：チームの運用状況を見る

**日付**：2026-11-04 | **計画**：[../plan.md](../plan.md) | **モック**：https://claude.ai/artifact/ESSqiqhGna9qZ56YFBUKg1

## 1. チームの画面 `/teams/:teamId`（変える）

- `statusVisible` が真の人にだけ、人数の行の「担当を決める」の左に「運用状況」のボタン（outline、`h-10 rounded-full md:h-9`）を置く。`/teams/:teamId/status` へ移る。
- `stoppedCount` が1以上なら、ボタンの中に件数の印（`bg-warning-bg text-warning`、11px）を付ける。件数は `GET /api/teams/:teamId/status` の結果（運用状況の画面と同じ問い合わせのキー）。この印は新しい強調だが、モック（2026-11-04）で決めた（spec FR-031の例外）。
- 閉じたトグル「チームで見えること」を、メンバー一覧の下に置く（全員）。箇条書き：
  - 「チームに見せる」をオンにしたアカウントは、チームの人が投稿ストックと戦略を読めます
  - 管理者と、担当の編集者は、運用状況（投稿の数・伸び・最後に動いた日）を見られます
  - 投稿の本文や戦略は、運用状況には出ません

## 2. 運用状況 `/teams/:teamId/status`（新規）

- 上部バー：戻る（`/teams/:teamId`）・題「運用状況」。パソコンはパンくず「チーム名 › 運用状況」。
- 一行の説明：管理者は「チーム名 · 見えるのは管理者と担当の編集者だけ」、編集者は「チーム名 · あなたの担当のアカウントだけ」。
- 閉じたトグル「見方」（箇条書き）：7日より長く動きがないと「止まっている」／伸びは、直近30日の閲覧数を前の30日と比べた値／×0.8以下で「伸びていない」／見えるのは数と日付だけ。投稿の本文や戦略は見えません。
- 「人」の一覧：名前・ロール・最後に動いた日（「今日」「昨日」「10/26（9日前）」「まだありません」「90日以内にありません」）・7日の動き（「7日で14回」）・「止まっている」の印。
- 「アカウント」の一覧：アイコン・名前・オーナー（「田中さんのアカウント」「あなたのアカウント」）・最後の投稿・7日の投稿・承認済み・要確認・伸び・印。
  - 伸び：`poor` は低調と同じ青の右下がりの矢印と比（×0.6）と「伸びていない」、`ok` は灰色の比、`insufficient` は「まだ判定できません」、`metrics_off` は「取り込んでいません」。
  - `connection` が `disconnected` なら「接続が切れています」を添える。
- スマートフォン（`< md`）は行を縦に積み、横にスクロールさせない（FR-032）。パソコンは表（列：人＝名前・ロール・最後に動いた日・7日の動き・印、Account＝アカウント・最後の投稿・7日の投稿・承認済み・要確認・伸び）。
- 読み込み中は `LoadingSkeleton`、失敗は `ApiErrorScreen`（`FEATURE_DISABLED` は019の使えない画面）。`ROLE_FORBIDDEN` はチームの画面へ戻す案内（「この画面は、管理者と担当の編集者だけが見られます」）。
- 行を押しても、Accountは開かない（開けるかどうかは今のチームの画面のまま。FR-003）。

## 3. 招待の確認の画面 `/invite/:token`（変える）

「メンバーとして入ります」の説明の後に、1文を足す：「管理者と、あなたのアカウントの担当の編集者は、運用状況（投稿の数・伸び・最後に動いた日）を見られます。投稿の本文や戦略は見られません。」

## 4. 変えないところ

- サイドバー・切り替えメニュー・個人運用の画面（FR-033・SC-005）。
- チームの画面の、メンバー・ロール・担当・見せる設定の操作。
