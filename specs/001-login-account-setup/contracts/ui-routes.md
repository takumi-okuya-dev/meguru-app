# UI契約：画面とルーティング

**対象feature**：[spec.md](../spec.md) ／ **API**：[api.md](./api.md)

`apps/web`（React SPA）の画面一覧・遷移の規則・表示文言の契約。見た目の細部（色・余白・タイポグラフィ）は、アプリ全体のデザインを決める段階で改めて定める。ここで決めるのは、後続featureが引き継ぐ画面の骨格だけである（research.md R11）。

## レイアウトの骨格

```text
┌──────────────┬────────────────────────────────────┐
│ サイドバー   │ メインパネル                       │
│              │                                    │
│ [Account ▾]  │  （各画面の内容）                  │
│  ・@takumi ● │                                    │
│  ・@ai_bu  ⚠ │                                    │
│ ＋ 追加      │                                    │
│              │                                    │
│ ─────────    │                                    │
│ ユーザー名 ▾ │                                    │
│  ログアウト  │                                    │
└──────────────┴────────────────────────────────────┘
```

- **サイドバー**：Accountの一覧と切り替え（FR-007）、「＋ 追加」、ユーザーメニュー（ログアウト、FR-006）。`needs_reconnect`のAccountには警告アイコンを付ける（FR-019）。
- **狭い画面**：サイドバーはメニューボタンで開閉するドロワーにする。
- **ダークモード**：OSの設定に従う。
- **ログイン画面とアカウント追加画面（0件時）**：サイドバーを出さず、中央寄せの1カラムにする。

## ルート

| パス | 認証 | 内容 | 対応する要件 |
|---|---|---|---|
| `/sign-in` | 不要 | 「Googleでログイン」ボタンだけの画面。ログイン済みなら`/`へ | FR-001 |
| `/` | 必要 | 中身を持たない振り分け用のルート。`GET /api/me`の`landingAccountId`があれば`/accounts/:id`、なければ`/accounts/new`へ置き換え遷移する | FR-004、FR-005 |
| `/accounts/new` | 必要 | アカウント追加画面。上限の表示、「Threadsアカウントを接続」ボタン、テスター制限の案内 | FR-008、FR-017 |
| `/accounts/:accountId` | 必要 | Accountのホーム。本featureでは、プロフィール（画像・表示名・@ユーザー名）と接続状態のみを表示する。後続featureがここに機能を足す | US1 |
| `/accounts/:accountId/settings` | 必要 | 接続状態、「再接続」ボタン、Accountの削除 | FR-019、FR-020、FR-022 |
| `/data-deletion/:code` | 不要 | Metaのデータ削除の受付表示（api.md参照） | research.md R7 |
| 上記以外 | — | 404画面 | — |

## 遷移の規則

1. **未ログインのガード**：認証が必要なルートに未ログインでアクセスしたら、内容を描画する前に`/sign-in`へ置き換え遷移する（FR-003）。ローディング中は骨組みだけを表示し、データは出さない。
2. **ログイン後**：常に`/`を経由して振り分ける（FR-004、FR-005）。直前に開こうとしていたURLへは戻さない（spec FR-004に従う）。
3. **Account 0件のガード**：Accountが0件のユーザーが`/accounts/:accountId`系にアクセスしたら、`/accounts/new`へ置き換え遷移する（US1 シナリオ3）。
4. **他人・存在しないAccount**：APIが`404 ACCOUNT_NOT_FOUND`を返したら404画面を出し、「自分のAccountへ戻る」リンクを置く。
5. **Accountの切り替え**：サイドバーで選んだら`PUT /api/me/last-account`を呼び、`/accounts/:id`へ遷移する（FR-007）。呼び出しの失敗は遷移を妨げない。
6. **ログアウト**：Clerkのセッションを終了し、TanStack Queryのキャッシュを全部消してから`/sign-in`へ置き換え遷移する。ブラウザの「戻る」で戻っても、ガード1により内容は表示されない（FR-006）。
7. **セッション切れ**：APIが`401`を返したら、「セッションの有効期限が切れました。もう一度ログインしてください」と表示してから`/sign-in`へ遷移する（spec エッジケース）。
8. **上限到達**：`/accounts/new`は、`accountLimit.used >= accountLimit.max`のとき接続ボタンを無効にし、上限の案内を出す。APIの`409`を受けた場合も同じ表示にする（FR-017）。
9. **削除の確認**：`/accounts/:id/settings`の削除ダイアログでは、`@username`を入力欄に打ち込むまで「削除する」ボタンを無効にする（FR-022）。削除後は`/`へ遷移して振り分け直す。

## callbackの結果表示

APIからのリダイレクトのクエリ（`connected`、`error`）を読み取り、トーストまたは画面内の通知で表示する。表示したらクエリはURLから消す。

| クエリ | 表示 |
|---|---|
| `connected=new` | 「@{username} を追加しました」 |
| `connected=updated` | 「@{username} はすでに登録済みのため、接続情報を更新しました」 |
| `connected=reconnect` | 「@{username} を再接続しました」 |
| `error=<code>` | 下の表の文言と、再試行のボタン |

## エラー文言（`packages/shared`に置く）

| code | 文言 | 次に取れる操作 |
|---|---|---|
| `AUTH_REQUIRED` | セッションの有効期限が切れました。もう一度ログインしてください。 | ログイン画面へ |
| `ACCOUNT_NOT_FOUND` | このAccountは見つかりません。削除されたか、アクセスする権限がありません。 | 自分のAccountへ戻る |
| `ACCOUNT_LIMIT_REACHED` | 現在のプランで登録できるAccount数（{max}件）に達しています。プラン3以上にすると最大5件まで登録できます。 | プランの案内（課金featureまでは問い合わせ先） |
| `THREADS_AUTH_CANCELLED` | Threadsとの接続がキャンセルされました。 | もう一度接続する |
| `THREADS_AUTH_FAILED` | Threadsとの接続に失敗しました。時間をおいてもう一度お試しください。 | もう一度接続する |
| `THREADS_PROFILE_FETCH_FAILED` | Threadsアカウントの情報を取得できませんでした。もう一度お試しください。 | もう一度接続する |
| `THREADS_ACCOUNT_TAKEN` | このThreadsアカウントは別のユーザーが登録済みです。 | 別のアカウントで接続する |
| `RECONNECT_ACCOUNT_MISMATCH` | 再接続には、元の@{username}で認可してください。別のアカウントで認可されました。 | もう一度再接続する |
| `OAUTH_STATE_INVALID` | 接続の有効期限が切れました。最初からやり直してください。 | もう一度接続する |
| `CONFIRMATION_MISMATCH` | 入力したユーザー名が一致しません。 | 入力し直す |
| （Googleログインの失敗） | Googleでのログインに失敗しました。もう一度お試しください。 | もう一度ログインする |

## 常時表示する案内

- **`/accounts/new`**：「現在は検証期間中のため、招待されたThreadsアカウントのみ接続できます。接続できない場合は運営者にお問い合わせください。」と問い合わせ先を表示する（research.md R3）。
- **`needs_reconnect`のAccount**：`/accounts/:id`の上部に、「Threadsとの接続が切れています。再接続するまで、このAccountの自動処理は止まります。」というバナーと「再接続」ボタンを出す（FR-019）。
