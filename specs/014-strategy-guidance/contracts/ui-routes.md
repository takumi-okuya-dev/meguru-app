## 課題（`/strategy`）

上から：上部バー（「課題」・完了n/16・要確認n・目的n/5問・最終更新・保存）→ 固定の区分のチップ → 案内の文 → 進み具合のカード → 区分ごとの項目。

- **固定の区分のチップ**（FR-018・FR-019）：上部バーの下に、PCでもスマートフォンでも固定する。「目的1/5」「営業導線2/5」「アカウント0/3」「集客導線0/4」「人柄1/2」「その他1/2」「下書き」。すべて十分なら✓。今見ている区分を塗りつぶす。押すと見出しへ移る。
- **進み具合のカード**（FR-014・FR-015）：完了n/16項目・要確認n件・活動の目的n/5問、バー、「次におすすめ：〇〇」（押すと項目へ移り、直せる人なら入力欄にカーソル）、「全体をAIと整理する」（直せる人だけ）。すべて十分なら「すべての項目が十分に書けています」。
- **項目**：項目名・印（★特に大事／任意／十分・短め・未入力）・説明・（★のとき考え方の説明）・入力欄・短めの一言と文字数・「考えるヒント」（閉じた状態）・「AIと深掘り」（直せる人だけ）。
  - 2026-11-02：利用者の要望で、ボタンの名前を「この項目をAIと深掘りする」から「AIと深掘り」に短くした。考えるヒントは、開いても「（閉じる）」を足さず、先頭の矢印の向き（▶／▼）で開閉を示す（Notionのトグルと同じ）。開いても2つのボタンの位置が変わらない。
- **考えるヒント**（FR-001〜FR-004）：コツ、悪い例と良い例（横に2つ。狭い幅では縦）、足してみたら、こんな場合は、もっと良くするなら。
- **AIと深掘りする**（FR-030〜FR-035）：同時に1項目だけ開く。3つの手順、「プロンプトをコピーする」、貼り付け欄、反映する内容（目印の内側か全体か）、「この内容を反映する」（空なら押せない）・「閉じる」、「反映しても、まだ保存されません」。
- **活動の軸**：「5問からAIと整理する」（5問がすべて空なら押せず「先にQ1〜Q5のどれかに答えてください」）。
- **下書きの区分**の説明：「Threadsには自動で反映されない下書きです。投稿づくりでは、投稿の方向性の軸として使います」（FR-021）。
- **全体をAIと整理する**：押すとコピーし、「コピーしました。ChatGPTやClaudeに貼り付けて送ると、項目どうしの重複・矛盾・抜けを質問の形で返してくれます」。
- コピーできなかったとき：プロンプトを選べる形で出し、「コピーできませんでした。全体を選んでコピーしてください」（003と同じ）。

## リサーチ（`/research`）

上から：上部バー（「リサーチ」・参考投稿のタブのときは「参考投稿を追加」）→ タブ（参考投稿n件・キーワードn件）→ 「伸びる投稿を見つけるリサーチ」（閉じた状態）→ タブの中身。

- **伸びる投稿を見つけるリサーチ**（FR-060）：①3つの指標 ②真似してよい投稿 ③真似しない方がよい投稿と例外 ④5つの手順 ⑤登録する前の5つの確認といちばん大事な考え方。
- **参考投稿を追加**（FR-080〜FR-085・FR-095〜FR-097）：一覧の上に開く欄。
  - 案内：「何件かまとめて登録するときは、1件入れるたびに『この投稿をためて、次の投稿を入力する』を押してください」
  - ためた投稿（n件）：書き出し・媒体・鮮度・解説の有無・「外す」
  - 本文（必須）、媒体（初めThreads）、元の投稿の投稿日（初め不明。「日付を入力する」で日付の欄）、鮮度の説明と今の入力の鮮度、投稿のURL、検索したキーワード
  - 「投稿の数字・投稿者（分かる場合だけ）」（初めは閉じる）：いいね・コメント・閲覧数・保存数・リポスト・投稿者のフォロワー数・投稿者・メモ
  - なぜ良いか（任意）：「空のままで大丈夫です。登録した後に、解説がまだの参考投稿をまとめてAIに解説してもらえます」
  - 「＋この投稿をためて、次の投稿を入力する」・「登録する」／「〇件を登録する」・「参考投稿はあと〇件まで登録できます」
  - ためた投稿か入力があるときに閉じる・離れるなら「登録していない投稿があります。破棄しますか？」
- **まとめてAIに解説してもらう**（FR-100〜FR-105）：一覧の上。「解説がまだの参考投稿：n件」「まとめてAIに解説してもらう（最大10件）」。押すとコピーし、貼り付け欄。貼ると「参考投稿：書き出し → 解説の書き出し」のチェック付きの一覧（理由の印：対応する参考投稿が見つかりません・すでに解説があります・同じIDが2回あります・解説が空です・長すぎます）。「〇件の解説を保存する」→「〇件の解説を保存しました」（飛ばした分があれば「〇件は、ほかで解説が入っていたため保存しませんでした」）。
- **参考投稿の一覧**のカード：媒体・鮮度・解説あり／なし・キーワード・閲覧といいね（分かれば）・本文・なぜ良いか。
- **参考投稿の編集**：追加の欄と同じ項目（ためるはない）＋「AIに解説してもらう」（1件の解説のプロンプトのコピー・貼り付け欄・「なぜ良いかに入れる」）。
- **キーワード**（FR-090〜FR-093）：「何を検索すればいいか迷ったら」のカード（「AIにキーワードの案を出してもらう」・貼り付け欄・チェック付きの一覧・「〇件を登録する」）、キーワードの一覧の各行に「Threadsで検索」（新しいタブ）。

## 投稿をつくる（`/create`。新規）

サイドバーの「投稿をつくる」で開き、この画面を開いている間はサイドバーの「投稿をつくる」を選ばれた見た目にする。上から：

1. 上部バー：「投稿をつくる」。
2. **投稿ができるまでの5つの手順**（FR-130）：①材料を埋める（課題・宣伝内容・リサーチへのリンク）②プロンプトをコピーする ③ChatGPTやClaudeに送る ④答えを貼り付けて登録する ⑤確かめて承認する（投稿ストックで）。「閉じる」で見出し1行。
3. **プロンプトのカード**（今の`PromptCard`を広げる）：
   - 見出し・作る件数
   - 「プロンプトに入っている情報」（初めは閉じる。FR-120〜FR-123）：1行のまとめ、開くと課題の判定と文字数の一覧（「編集」）、下書き・宣伝内容・リサーチのカード（「編集」・「解説がまだn件 → まとめてAIに解説してもらう」）
   - 「文字数と長さの割合」（初めは閉じる。FR-140〜FR-142）：1行のまとめ、目標の文字数、短文・中文・長文の文字数と割合（スライダー）と件数、内訳、理由の文、「保存」・「初期値に戻す」。オーナーだけが保存できる（今の作る件数と同じ）。
   - プロンプトの長さ「約n字」と、送り方「1つにまとめて送る／2つに分けて送る（おすすめ）」（FR-150〜FR-153）。12,000字を超えると注意の文。
   - 1つにまとめて：「プロンプトをコピー」「中身を見る」（今の書き換えてコピー）。2つに分けて：「① 1つ目 ― 送ったら、AIの『受け取りました』を待つ」「② 2つ目（最後） ― これを送ると、投稿が作られます」それぞれに字数・コピー・中身を見る。
   - プロンプトを作れない状態の案内は今のカードのまま（013の読むだけなど）。
4. **貼り付け欄**（今の`PasteComposer`を、画面の下に固定せずこの画面に置く）：見出し「AIの答えを貼り付けて、投稿ストックに登録する」、コピーの注意（FR-131）、「自分で1件書く：AIを使わずに、1件の本文を書いて登録することもできます」と「リサーチした投稿を、自分なりに真似して書いてみよう → リサーチを見る」（FR-132）、「投稿ストックに登録する」。登録の後は今の結果の表示に「〇件を投稿ストックに登録しました」と「投稿ストックで確かめる →」（`/stock`。要確認のタブ）。

入れる人：今の投稿ストックでプロンプトのカードと貼り付け欄を使える人と同じ。見せてもらっているアカウントの画面（`/teams/:teamId/accounts/:accountId`）には出さない。

## 投稿ストック（`/stock`）

- 上部バー：「投稿ストック」と右に「投稿をつくる」のボタン（`/create`）。
- 今の自動投稿の知らせ・状態のタブ・下書きの一覧・投稿済み・まとめての承認・選択のバーは今のまま。
- プロンプトのカードと、画面の下に固定の貼り付け欄は置かない。
- 下書きが1件もない（要確認のタブ）：「まだ投稿がありません」「『投稿をつくる』で、AIに作ってもらった投稿や、自分で書いた投稿を登録できます」と「投稿をつくる」のボタン（FR-163）。

## ホーム（`/accounts/:accountId`）

- **はじめに読んでほしいこと**（FR-061）：自分のアカウントのホームの一番上。初めは開いた状態で、「閉じる」で見出し1行（押すと開く）。閉じたことは端末に覚える（利用者ごと）。文：SNSの運用は地道／続けることがいちばんの力・始めは反応が少ないのが当たり前／成果は約束できない／SNSの時間を先に予定に入れる（通勤中・寝る前の15分など）／完璧を目指さず小さく試して直す。
- 「次にやること」の「投稿をつくりましょう」のボタンは`/create`へ（FR-164）。

## 文言の一覧（新しい・変わる主なもの）

| 場所 | 文言 |
|---|---|
| 課題・項目の印 | 十分／短め／未入力／★ 特に大事／任意 |
| 課題・短めの一言（共通） | 出来事・気持ち・具体的な場面を1つ足すと、ぐっと伝わりやすくなります |
| 課題・深掘りの手順 | ①「プロンプトをコピーする」を押す ②ChatGPTやClaudeに貼り付けて送り、AIの質問に答える ③AIが出した完成版を、答えごと下に貼り付けて「この内容を反映する」 |
| 課題・反映する内容 | 反映する内容（目印「【完成版ここから】」の内側）／目印が見つからないので、貼り付けた文の全体を反映します |
| 課題・上限を超える | 〇文字を超えています。反映した後に短くしてください |
| リサーチ・ためる | ＋この投稿をためて、次の投稿を入力する |
| リサーチ・上限 | 参考投稿はあと〇件まで登録できます |
| 投稿をつくる・長い | プロンプトが長いです。無料のAIでは途中で切られることがあります。2つに分けて送るのがおすすめです |
| 投稿をつくる・割合 | 割合の合計を100%にしてください（今は〇%）／〇〇の文字数は、目標の〇字以下にしてください |
| 投稿をつくる・登録の後 | 〇件を投稿ストックに登録しました／投稿ストックで確かめる |
| 投稿ストック・空 | まだ投稿がありません |

## スマートフォンの幅（375px）

- 課題：チップは横スクロール（今のまま）で、完了・要確認の数を先頭に出す（FR-017）。ヒントの悪い例・良い例は縦に並べる。
- リサーチ：数字の欄は2列、ためた投稿は縦に並べる。
- 投稿をつくる：短文・中文・長文のカードは縦に並べる。2つに分けたときの各行は、ボタンが折り返す。
- どの画面も横にはみ出さない（SC-009）。
