## 契約と支払い（`/settings/billing`）

見出し「契約と支払い」。カード1枚に状態、もう1枚に料金の説明、下に規約へのリンク。

| 状態（`state`） | 状態の行 | 中身 | ボタン |
|---|---|---|---|
| `billing_disabled` | 「この環境では決済を使いません」 | なし | なし |
| `exempt` | 「料金なし」 | 「料金はかかりません」 | なし |
| `trial` | 「無料体験中：〇月〇日まで（あと〇日）」 | アカウント〇件。「契約しても、無料体験が終わるまで料金はかかりません」 | 「契約する」 |
| `subscribed_trial` | 「無料体験中（契約済み）」 | 最初の請求日〇月〇日・見込み〇円・アカウント〇件 | 「支払いの画面を開く」 |
| `active` | 「契約中」 | 次の請求日・見込み・アカウント〇件 | 「支払いの画面を開く」 |
| `canceling` | 「〇月〇日に終わります（解約済み）」 | 「その日まで、すべての機能を使えます。解約は支払いの画面から取り消せます」 | 「支払いの画面を開く」 |
| `read_only`（`trial_ended`） | 「無料体験が終わりました」 | 「今は読むだけです。契約すると、すぐに元どおり使えます」 | 「契約する」 |
| `read_only`（`canceled`） | 「契約が終わりました」 | 同上 | 「契約する」 |
| `read_only`（`payment_failed`） | 「支払いに失敗しました」 | 「カードを更新すると、すぐに元どおり使えます」 | 「支払いの画面を開く」 |

- 料金の説明：「基本料金 月1,000円（アカウント1件目を含む）／2件目から1件につき月500円（税込み）。アカウントの数は次の請求から反映し、日割りはしません」。金額は`prices`から出す。
- 「契約する」の上に「利用規約」「特定商取引法に基づく表記」へのリンク（SC-009）。
- 「契約する」「支払いの画面を開く」：押すと`POST /api/billing/checkout`・`portal`の`url`へ移る。押している間はボタンを止め、「支払いの画面に移っています…」。`BILLING_UNAVAILABLE`ならトースト。
- `?checkout=success`で開いたら、`POST /api/billing/sync`を呼び、読み込みの間「契約を確かめています…」。`subscribed_trial`か`active`になったら「契約しました」のトーストを出し、URLから`?checkout`を消す。10秒たっても変わらなければ、「確かめるのに時間がかかっています。少し待ってから開き直してください」。
- `?checkout=canceled`なら何も出さず、URLから消す。
- 画面を開くたびに`POST /api/billing/sync`を1回呼ぶ（契約がある人だけ。FR-036）。
- 個人運用の人に、チームの説明を出さない（FR-072）。

## 帯

### 無料体験の終わりの帯（アプリ全体）

- 出す条件：`GET /api/me`の`billing.state = trial`で、`trialDaysLeft <= 7`。
- 置き場所：サイドバーの右のメインの一番上（アカウントの画面・設定・チームの画面すべて）。
- 文言：「無料体験はあと〇日で終わります。続けて使うには契約してください」（0日なら「無料体験は今日で終わります」）と「契約する」（`/settings/billing`）と閉じるボタン。
- 閉じたら、その日（日本時間）は出さない（`localStorage`。読めなければ毎回出す）。

### 読むだけの帯（アカウントの画面）

- 出す条件：`GET /api/accounts/:id/access`の`readOnly`が`null`でない。
- 置き場所：アカウントの画面の一番上（今の`GrowerRequiredBanner`と未接続の帯の場所。両方あるときは読むだけの帯を上に）。閉じられない。
- 文言：

| `reason` | 文言 | ボタン |
|---|---|---|
| `trial_ended` | 「無料体験が終わりました。今は読むだけです。契約すると、すぐに元どおり使えます」 | 「契約する」 |
| `canceled` | 「契約が終わりました。今は読むだけです。契約すると、すぐに元どおり使えます」 | 「契約する」 |
| `payment_failed` | 「支払いに失敗しました。カードを更新してください。更新するまで読むだけです」 | 「支払いの画面を開く」 |
| `owner_inactive` | 「オーナーの契約の状態により、このアカウントは今、読むだけです」 | なし |

- 書き込みのボタンは、今の`can(permission)`の出し分けのまま（権限が絞られて返るので、出ない・押せない形になる）。
- 保存の途中で`403 BILLING_REQUIRED`を受けたら、ダイアログ「編集できなくなりました」と帯と同じ文言を出す。入力は画面に残す（今の`GrowerRequiredDialog`を置き換える）。
- 自動投稿の状態の知らせ（005の`AutoPostNotices`）に、飛ばした理由`billing_inactive`の文「契約が止まっていたため、この時刻は投稿しませんでした」を足す。

## アカウントを作る（`/accounts/new`。012から）

| 条件（`GET /api/me`の`billing`と`accountLimit`） | 画面 |
|---|---|
| 作れる（`max`が`null`か、`used < max`）で、`state`が`subscribed_trial`・`active`・`canceling`で`used >= 1` | 名前の入力の下に「2件目からは1件につき月500円です。次の請求から反映されます」（FR-031） |
| `state = trial`で`used >= 1` | 入力欄の代わりに「無料体験中に作れるアカウントは1件までです。契約すると、2件目から1件につき月500円で足せます」と「契約する」 |
| `state = read_only` | 入力欄の代わりに理由の文（帯と同じ）と「契約する」か「支払いの画面を開く」。アカウントが0件の人（spec Edge Cases）はサイドバーなしの1カラムのまま |
| そのほか | 今のまま |

切り替えメニューの「アカウントを作る」は、作れないときも出し、押すとこの画面で理由を出す（今のまま）。

## 退会（`/settings/account`）

- 「ログアウト」のカードの下に、離して「退会」のカード：「退会すると、あなたのアカウントとデータがすべて消え、元に戻せません」と「退会する」（赤の枠のボタン）。
- 押すと`GET /api/me/withdrawal-preview`を読んで、ダイアログ「退会しますか？」：
  - 「消えるもの」：オーナーのアカウントの名前の一覧（〇件）、「戦略・投稿ストック・設定・パフォーマンス・Threadsとのつながり・予約中の自動投稿」。0件なら「あなたのアカウントはありません」。
  - 「チーム」（入っていれば）：チームごとに「〇〇：△△さんに管理者を引き継ぎます」「〇〇：チームを削除します」「〇〇：チームから外れます」。
  - 契約中なら「契約はすぐに止まり、残りの期間の返金はありません」。
  - 「確認のため、メールアドレス（user@example.com）を入れてください」と入力欄。合うまで「退会する」は押せない（大文字・小文字と前後の空白は区別しない）。
  - 「キャンセル」「退会する」（危険な操作の色）。
- 押している間は「退会しています…」で、ダイアログを閉じられない。
- 成功：Clerkからログアウトし、`/?withdrawn=1`へ。
- 失敗：`BILLING_UNAVAILABLE`はダイアログの中に文言を出し、もう一度押せる。`CONFIRMATION_MISMATCH`は入力欄の下に「メールアドレスが違います」。
- `WITHDRAWAL_IN_PROGRESS`を受けた画面は、「退会の手続きの途中です」の画面に替え、「退会する」（同じダイアログ。プレビューは読み直す）だけを出す。

## 特定商取引法に基づく表記（`/legal/commerce`）

表の項目：販売事業者、運営責任者、所在地、電話番号、メールアドレス、販売価格（`prices`の定数から）、商品代金以外の必要料金（なし。通信料は利用者の負担）、支払い方法（クレジットカード）、支払いの時期（無料体験の終わり、または契約したとき。以後毎月）、提供の時期（契約の手続きが終わってすぐ）、解約・返品（いつでも解約でき、期間の終わりまで使える。日割りの返金はしない）、動作環境。

- 販売者の情報は、公開の前に運用が入れる（spec FR-071）。それまでは「（公開の前に記入）」と出す。住所・電話番号は「請求があれば遅滞なく開示します」と書く形も選べる（手順書に書く）。

## 利用規約（`/terms`）に足す節

「料金と支払い」「無料体験」「解約」「未払いのとき」「退会」の5つ（spec US7-2の内容）。金額は`prices`の定数から出す。今の「料金・解約・特定商取引法に基づく表示は 011（決済）で足す」のコメントを消す。
