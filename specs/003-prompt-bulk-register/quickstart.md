# 動作確認ガイド（Quickstart）：AIプロンプトの生成と投稿案の一括登録

**対象feature**：[spec.md](./spec.md) ／ **契約**：[contracts/api.md](./contracts/api.md)、[contracts/ui-routes.md](./contracts/ui-routes.md)、[contracts/prompt-template.md](./contracts/prompt-template.md)

本featureが端から端まで動くことを確かめる手順。実装コードは含めない。

## 前提

- 002までのセットアップ（[002 quickstart.md](../002-strategy-profile/quickstart.md)）が済んでいる。
- 本featureもThreads APIを呼ばないので、`pnpm dev:fake`で確認できる。
- 外部LLM（ChatGPTかClaude）を使えるブラウザ。

## セットアップ

```bash
pnpm install
docker compose up -d
pnpm --filter api db:migrate        # 本featureのマイグレーション（テーブル2つと accounts の列1つ）
pnpm dev:fake
```

## 自動テスト

```bash
pnpm --filter @threads-grower/shared test
pnpm --filter api test
pnpm --filter web test
```

**期待する結果**：すべて成功する。とくに次のテストがあり、成功していること。

## 手動の確認

`pnpm dev:fake`で起動した画面で確かめる。

### 1. プロンプト（US1）

1. 002の課題・宣伝内容・リサーチを入力したAccountで、サイドバーの「投稿ストック」を開く。
2. カードの要約に、入力した課題の項目数・宣伝の対象の件数・参考投稿の件数が出ている。
3. 「プロンプトを見る」で全文を開き、[prompt-template.md](./contracts/prompt-template.md)の節の順になっていること、未入力の項目がないことを確かめる。
4. 作る件数を10に変えて再読み込みしても10のまま。別のブラウザで開いても10。
5. 「コピー」を押し、ChatGPTかClaudeに貼り付けて送る。「@@@」で区切られた10件が返ってくる。

### 2. 一括登録と取り消し（US2）

1. 外部LLMの回答をまるごと、画面下部の貼り付け欄に貼り付けて送る。
2. 「10件を登録しました」が出て、一覧の先頭に回答と同じ順で並ぶ。
3. 「取り消す」を押すと10件が消え、貼り付けた内容が欄に戻る。もう一度送って登録し直す。
4. 区切りのないテキストを送ると、1件として登録され、区切りが見つからなかった案内が出る。

### 3. 下書きの確認・修正・削除（US3）

1. 1件の「⋯」から「編集」で本文を直して保存すると、一覧に反映される。
2. 絵文字を多く含む下書きでは、長さのバーが文字数以上に伸びる。上限を超えると注意の色と案内が出る。
3. 3件を選ぶと、貼り付け欄の位置に選択のバーが出る。「選んだ下書きを削除」で確認なしに3件が消え、トーストの「元に戻す」で戻る。もう一度消して5秒待つと、再読み込みしても消えたまま。

### 4. プランと画面幅

1. `pnpm --filter api db:psql`でユーザーの`users.created_at`を1か月以上前にし、Accountのプランを`auto-only`にする。プロンプトのカードの代わりにプラン2以上の案内が出て、貼り付けによる登録はできる。
2. 375・768・1024・1440pxで、プロンプトのカード・一覧・貼り付け欄・選択のバーが崩れない。375pxで貼り付け欄が画面下端の操作バーに重ならない。
