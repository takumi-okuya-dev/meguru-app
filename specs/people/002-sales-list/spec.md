# Feature Specification：人物メモを「声かけリスト」として使う（タグ・次にやること・連絡の記録・来てくれそう度・会ごとの声かけ・自由な項目・書き出し）

**Feature Branch**: `feature/people-002-sales-list`

**Created**: 2026-11-13

**Status**: Draft

**Input**: 人物メモ（specs/people/001-people-memo）を、「人物メモ＋営業リスト（イベントに来てくれそうな人に声をかける）」として使えるようにする。似たアプリ「人記録」（人の管理のメモとプロフィール帳。iPhone）の機能のうち、作り手の使い方に合うものを取り込む。

**Source**: 001 の [spec.md](../001-people-memo/spec.md)・[data-model.md](../001-people-memo/data-model.md)・[research.md](../001-people-memo/research.md)、似たアプリの紹介記事（note.com/hitokiroku/n/ne16560e06a0d）、[docs/parallel-development.md](../../../docs/parallel-development.md) 11章。

## Clarifications

### Session 2026-11-13（ユーザーと決めたこと）

- Q：似たアプリ「人記録」のどの機能を取り込むか？ → A：**タグと並べ方・書き出し・自由な項目とSNSのリンク・リマインダー**の4つ。写真・画像から読み取るAI・住所や電話などの欄は、001の決めごと（写真なし・持つ個人の情報を増やさない）に合わせて取り込まない。
- Q：理想の形は？ → A：**人物メモ＋営業リスト**（イベントに来てくれそうな人に声をかける）。そのために、**次にやること・連絡の記録・来てくれそう度・会ごとの声かけの一覧**の4つも足す。
- リマインダーは「次にやること」にまとめる：人ごとに「いつ・何をするか」を決め、ホームに「今日やること・過ぎたもの」を出す。誕生日（月日だけ）も「近い誕生日」として出す。メールやスマートフォンへの知らせは、仕組みが大きいので次の段に回す。

## 用語（001に足すもの）

- **タグ**：作り手が人に付ける短い名前（例：常連・登壇してくれそう・港の相談）。1人に複数付けられる。作り手ごとに持つ。
- **次にやること**：人ごとに1つ、「いつ（日付）」と「何をするか（短い文）」。終わったら消すか、次の日付に変える。
- **連絡の記録**：いつ・何で（LINE・会場で・そのほか）・何を話したかの1行。人ごとに何件でも残す。
- **来てくれそう度**：作り手の見立て。高・中・低・なし。アンケートの「次回参加」の答えとは別。
- **自由な項目**：作り手が足す項目（例：好きなもの・紹介された本）。全員に同じ項目が出て、値は人ごとに入れる。
- **SNSのリンク**：Instagram・X・FacebookのプロフィールのURL。押すとそのページを開く。LINEは名前だけ（001のまま）。
- **並べ方**：一覧の並び（最後に会った順・初めて会った順・更新順・あいうえお順・来てくれそう度順）と、まとめた表示（なし・年月ごと・タグごと・あいうえおの行ごと）。選んだ並べ方は覚える。
- **会ごとの声かけの一覧**：誘う会ごとに、進み具合（興味を聞いた・参加リンクを送った・来た）ごとの人数と人を並べた画面。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - タグで人を分け、並べ方を選ぶ (Priority: P1)

作り手は人のページで「常連」「登壇してくれそう」などのタグを付ける。人の一覧と誘う候補でタグで絞り、並べ方（最後に会った順・あいうえお順など）とまとめた表示（年月ごと・タグごと）を選ぶ。次に開いても同じ並べ方で出る。

**Independent Test**：3人に「常連」、1人に「登壇してくれそう」を付ける → 一覧で「常連」で絞ると3人 → 「タグごと」にすると2つのまとまり → 開き直しても「タグごと」のまま。

1. **Given** タグのない人、**When** 人のページで新しいタグ「常連」を付ける、**Then** そのタグが作られ、人に付き、ほかの人にも選んで付けられる。
2. **Given** タグを付けた人がいる、**When** 一覧か誘う候補でタグを選ぶ、**Then** そのタグのどれかを持つ人だけが出る（誘う候補では、同意の絞り込みはそのまま）。
3. **Given** 一覧、**When** 並べ方とまとめた表示を選ぶ、**Then** その順と見出しで並び、次に開いても同じ。
4. **Given** タグ、**When** 名前を直す・消す、**Then** 付けていた人すべてに反映される（消すと外れる）。

### User Story 2 - 次にやることを決め、今日やる人を見る (Priority: P1)

作り手は人のページで「11/20 12月の会の案内を送る」のように次にやることを決める。ホームに「今日やること」と「過ぎたもの」が並び、終わったら「終わった」で消すか、次の日付に変える。誕生日（月日）を入れた人は「近い誕生日」に出る。

**Independent Test**：Aに今日、Bに昨日、Cに来週の次にやることを決める → ホームの「今日やること」にA、「過ぎたもの」にB、Cは出ない → Aを「終わった」にすると消え、連絡の記録に1行残る。

1. **Given** 人のページ、**When** 日付と文で次にやることを決める、**Then** 人のページと一覧に出る。
2. **Given** 今日か前の日付の次にやること、**When** ホームを開く、**Then** 「今日やること」「過ぎたもの」に、日付の順で並ぶ。
3. **Given** 次にやること、**When** 「終わった」を押す、**Then** 次にやることが消え、その内容が連絡の記録に「やったこと」として1行残る（記録しないも選べる）。
4. **Given** 誕生日（月日）を入れた人、**When** 今日から7日以内に誕生日がくる、**Then** ホームの「近い誕生日」に出る。年は持たない。

### User Story 3 - 連絡の記録を残す (Priority: P1)

作り手は、LINEで話した・会場で話したことを、日付つきで人のページに残す。前の「話したこと」のメモは残したまま、記録は時系列で増えていく。

1. **Given** 人のページ、**When** 日付（初めは今日）・何で（LINE・会場で・そのほか）・内容で記録を足す、**Then** 新しい順に並ぶ。
2. **Given** 記録、**When** 直す・消す、**Then** 反映される。
3. **Given** 記録のある人、**When** 一覧の探す欄に記録の言葉を入れる、**Then** その人が出る。

### User Story 4 - 来てくれそう度で並べ、絞る (Priority: P2)

作り手は人ごとに「来てくれそう度」（高・中・低）を付け、誘う候補を来てくれそう度の順に並べたり、「高」だけに絞ったりする。

1. **Given** 人のページか候補の行、**When** 来てくれそう度を選ぶ、**Then** 残り、一覧と候補に印が出る。
2. **Given** 誘う候補、**When** 「来てくれそう度の順」にする・「高」で絞る、**Then** そのとおりに並ぶ（同意の絞り込みはそのまま）。

### User Story 5 - 会ごとの声かけを一覧で見る (Priority: P2)

作り手は次の会について、「興味を聞いた」「参加リンクを送った」「来た」の人数と人を並べて見て、まだリンクを送っていない人に声をかける。

1. **Given** 誘う会への声かけがある、**When** その会の「声かけの一覧」を開く、**Then** 進み具合ごとに人数と人（名前・最後に会った日・来てくれそう度・次にやること）が並ぶ。
2. **Given** 一覧、**When** 人の進み具合を変える、**Then** そのまとまりへ移る。

### User Story 6 - 自由な項目とSNSのリンクを足す (Priority: P2)

作り手は「好きなもの」「紹介された本」のような項目を足し、人ごとに値を入れる。InstagramやXのプロフィールのURLを入れると、人のページにそのページを開くボタンが出る。

1. **Given** 設定、**When** 項目を足す・名前を直す・並べ替える・消す、**Then** 全員の人のページに、その順で出る（消すと値も消える）。
2. **Given** 人のページ、**When** 項目の値を入れる、**Then** 残り、探す欄で探せる。
3. **Given** 人のページ、**When** Instagram・X・FacebookのURLを入れる、**Then** そのサービスのURLのときだけ残り、押すとそのページを開く。

### User Story 7 - 人の一覧を書き出す (Priority: P2)

作り手は人の一覧をCSVで書き出し、Excelで開いて使う。

1. **Given** 人の一覧（絞り込みあり・なし）、**When** 「書き出す」を押す、**Then** 絞り込みに合う人のCSV（名前・LINE名・別名・タグ・最後に会った日・自分の会の回数・同意・来てくれそう度・次にやること・いちばん新しい答え・メモ・自由な項目・SNSのリンク）が保存される。Excelで文字化けしない。
2. 消した人は入らない。書き出しは、画面で押したときだけ作り、APIにもファイルを残さない。

### Edge Cases

- 人をまとめる：タグは両方を合わせ、自由な項目とSNSのリンクと次にやることと来てくれそう度は、残す人にあればそれ、なければ相手のもの。連絡の記録はすべて移す。
- 人を分ける：新しい人には、タグ・次にやること・連絡の記録・自由な項目は付けない（元の人に残る。001 R15と同じ考え）。
- 人を消す・退会：タグの付け方・次にやること・連絡の記録・自由な項目の値・SNSのリンクも一緒に消える。退会では、作り手のタグと自由な項目も消える。
- タグ・自由な項目の名前はnameKeyで比べて、同じ名前を2つ作らない。
- 書き出しのCSVの値が「=」「+」「-」「@」で始まるときは、Excelで式として読まれないよう頭に「'」を付ける。

## Requirements *(mandatory)*

- **FR-101**：作り手はタグを作り・直し・消せ、人に複数付け外しできる（1人に付けられるのは20まで、作り手のタグは100まで、名前は1〜30文字）。
- **FR-102**：人の一覧と誘う候補は、タグ（どれかを持つ）と来てくれそう度で絞れる。誘う候補の同意の絞り込みは、APIの問い合わせの条件のまま（001 FR-018）。
- **FR-103**：人の一覧は、並べ方（最後に会った順・初めて会った順・更新順・あいうえお順・来てくれそう度順）とまとめた表示（なし・年月ごと・タグごと・あいうえおの行ごと）を選べ、作り手ごとに覚える（どの端末でも同じ）。
- **FR-104**：人ごとに次にやること（日付・1〜200文字）を1つ持てる。ホームに今日やること・過ぎたもの・近い誕生日（7日以内）を出す。
- **FR-105**：人ごとに誕生日の月日（年は持たない）を持てる。
- **FR-106**：人ごとに連絡の記録（日付・何で〔LINE・会場で・そのほか〕・1〜1,000文字）を何件でも残せ、直し・消せる。探す欄で探せる。
- **FR-107**：人ごとに来てくれそう度（高・中・低・なし）を持てる。
- **FR-108**：誘う会ごとに、進み具合ごとの人数と人を一覧で見られ、そこから進み具合を変えられる。
- **FR-109**：作り手は自由な項目（1〜30文字、30まで）を足し・直し・並べ替え・消せる。値は1人1項目につき1〜500文字。探す欄で探せる。
- **FR-110**：人ごとにInstagram・X・FacebookのプロフィールのURL（https、そのサービスのドメインだけ、500文字まで）を持てる。
- **FR-111**：人の一覧（絞り込みに合う人）をCSV（UTF-8・BOMつき）で書き出せる。式として読まれる頭の文字は逃がす。APIは書き出しのファイルを残さない。
- **FR-112**：名前・メモ・記録・項目の値・URLを、ログ・ブラウザの保存・URLの道筋に入れない（001 R18と同じ）。書き出しのAPIは、絞り込みを本文で受ける。

## Success Criteria *(mandatory)*

- **SC-101**：次の会の前に、ホームの「今日やること」から声をかける人を1分以内に決められる。
- **SC-102**：会ごとの声かけの一覧で、まだリンクを送っていない人が、開いてすぐ（スクロールなしの1画面で）わかる。
- **SC-103**：書き出したCSVをExcelで開いて、文字化けせず、式として読まれる値がない。

## Assumptions

- 001 がすべてマージ済み（PR1〜PR4）。
- 知らせ（メール・スマートフォン）は作らない。
- タグ・自由な項目は作り手ごと（チームで分け合わない）。
