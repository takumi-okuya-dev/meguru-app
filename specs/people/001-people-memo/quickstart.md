## 1. 取り込み（User Story 1）

1. `/people/events/new`で「IT交流会 10/11」（2026-10-11・自分の会）を作る。
2. `/people/import`で`form-1011.csv`を選ぶ → イベント「IT交流会 10/11」を選ぶ → 列の対応で、10/11の質問文に初めから項目が当たっている（「初めから当てた」の印）。「今日の満足度」などは「どれにもあたらない」。
3. LINE名の列を「どれにもあたらない」に変えて次へ → 「LINE名の列を選んでください」で進めない（US1 AS3）。戻す。
4. 確かめの段で「新しく入る人 20人・同じ人の候補 0組・取り込めない行 0行」→ 取り込む（SC-001：ここまで5分以内）。
5. `/people/events/:id`に参加者20人・取り込み1件が出る。
6. 同じCSVをもう一度上げる → 「もう取り込んだ 20行」で、新しく入る人は0人（US1 AS5）。
7. Excelで開いて保存し直したCSV（Shift_JIS）を上げる → 文字化けせずに同じ見出しが出る。ZIPのまま上げる → ZIPの案内が出る。

## 2. 同じ人の候補（User Story 2の取り込みの中）

1. 「IT交流会 11/25」を作り、`form-1125.csv`を上げる → 「お名前（フルネーム・任意）」に本名が初めから当たり、ほかの列は覚えた対応で当たる（US1 AS2。SC-001：2分以内）。
2. 確かめの段で、同じ人の候補が5組（LINE名が同じ4組・「記号を除くとLINE名が同じ」1組）。各組に、前の人の来たイベント（IT交流会 10/11）と答えが並ぶ（SC-004）。
3. 4組を「つなぐ」、絵文字違いの1組を「別の人」→ 取り込む → 4人は来たイベントが2つ、1人は新しい人（US2の Independent Test）。
4. 候補の組を1つも選ばずに取り込もうとする → 取り込めず、決めていない組に戻る。

## 3. 人の一覧と人のページ（User Story 4・2・7。PR2のあと）

1. `/people/list`で「たろう🌸」の別名のLINE名の一部（「たろ」）を入れる → その人が出る（US4 AS1）。
2. 2回来た人のページを開く → 来た2つのイベント（新しい順）・それぞれの答え・LINE名の別名が出る。メモ「メガネ、Pythonの話」を足す → 開き直しても残り、一覧で「Python」で探すと出る（US4の Independent Test）。
3. 本名を直す → 一覧・探すに新しい本名が使われる。
4. 「たろう🌻」のページで「この人と同じ人」→「たろう🌸」を選ぶ → 1人にまとまり、来たイベント・回答・メモが集まる（US2 AS3）。
5. その人の11/25の回答で「別の人に分ける」→ 新しい人ができ、11/25の来た記録が移る（US2 AS4）。
6. 「人を足す」で、アンケートのない会で会った人（本名・LINE名・会ったイベント・交流会への誘いの同意あり）を足す → 一覧に出る（US2 AS5）。
7. 「個別の案内は希望しない」の人のページで、交流会への誘いの同意をONにする（口頭でOK）→ 同意の記録に「手で直した・日時」が出る。
8. 10/11だけに来た人のページで「この人を消す」→ 名前を入れて消す → 一覧・探すに出ない。`/people/events/:10/11`の参加者数は20人のまま（「消した人 1人」）（US7・SC-006）。
9. `form-1011.csv`をもう一度上げる → 消した人の行は「消した人の回答（取り込みません）」になる。

## 4. 誘う候補と声かけ（User Story 3・5。PR3のあと）

1. 「IT交流会 12/13」（2026-12-13・自分の会）を作る。`/people/settings`でリピーターの目標を10人にする。
2. `/people`を開く → 上に「リピーター 4人／目標 10人」（US5）。誘う会は「IT交流会 12/13」が初めから選ばれている。
3. 「前に来た」「次回参加：参加できそう」で絞る → 合う人だけが、最後に会った日の新しい順に並ぶ。「個別の案内は希望しない」と答えた人（3-7で手で同意した人を除く）は、どの絞り込みでも出ない（US3・SC-003）。
4. 1人の「文をコピー」→ 「〇〇さん、12月13日（土）のIT交流会 12/13、もしご興味あれば一緒にいかがですか？」がコピーされる → 「興味を聞いたにする」→ 行と人のページに「興味を聞いた」。もう一度「文をコピー」→「興味を聞いたにする」を押しても、声かけは1つのまま（US3 AS4）。
5. スマートフォン（390px幅）で、下のバーの「誘う候補」→「文をコピー」の2回で文がコピーされる（SC-005）。
6. `/people/events/:11/25`に「初めて 6人・前にも来た 4人」（US5の Independent Test）。
7. 12/13の会のあと、誘った人を含むCSVを取り込み、その人につなぐ → 進み具合が自動で「来た」になる（US3 AS5）。

## 5. 仕事の相談先へのつなぎ（User Story 6。PR4のあと）

1. `/people?purpose=work`を開く → 「転職・求人情報」か「副業・業務委託案件」に同意した人だけが並ぶ（US6 AS1）。
2. 1人で「声かけを始める」→ 相談先「〇〇社の採用」→ 「本人に聞いた」から始まる。「つないだ」のボタンは出ない。APIに直接`stage: "connected"`を送ると409 `OUTREACH_NEEDS_APPROVAL`（US6 AS3）。
3. 「OKをもらった」→「つないだ」→ 人のページに、いつ・どの相談先へ・あなたが記録、が残る（US6 AS4）。

## 6. 取り消し・イベントを消す・退会

1. 11/25の取り込みを「取り消す」→ メモを書いた人がいれば「書き足しのある人 n人」が出て、残すか消すかを選ぶ → 11/25の回答が消え、11/25だけで作られた人も消える（FR-008）。
2. イベント「IT交流会 12/13」を消す → 確かめのあと消え、その会への声かけも消える（FR-027）。
3. 運営者が自分の「めぐる 人物メモ」を閉じる → 人物メモを開けない。開き直すと前のまま（FR-031）。
4. テストユーザーで退会する → 退会の確かめに「人物メモ：人 n人・イベント n件が消えます」→ 10分以内に、その人の人物メモのデータが消える（FR-030）。

## 7. 自動のテスト

```bash
pnpm --filter @meguru/shared test     # CSVの読み方・名前の正規化・複数選択の分け方・同意の決め方・誘いの文
pnpm --filter api test                # 結合テスト（作業場所をまたいで1つずつ流れる）
pnpm --filter web test
pnpm e2e                              # 取り込み・誘う候補の流れ
pnpm lint                             # 境界の規則（apps/people がほかのアプリ・共通の表を読まない）
```

主に確かめること：同意のない人が候補に出ないこと（すべての絞り込みで）、同じ人が勝手につながらないこと、二重の取り込みがないこと、人を消しても参加者数が変わらないこと、ほかの作り手の人が404になること、利用の許可のない人が403になること、退会の出来事を2回受け取っても同じ結果、ログに名前が出ないこと。
