## 3. スマートフォン（390px幅。T096）

E2E（`e2e/tests/people-phone-width.spec.ts`）で、下の画面を390px幅で開き、3つを自動で確かめる（2026-11-14 に通った）。

- 横にスクロールしない（はみ出す要素がない）
- 押すところ（リンク・ボタン・入力・選ぶもの）の高さが44px以上。ラベルのあるものはラベルの大きさでも測る。文の中のリンクは除く
- 中身を一番下まで送ったとき、中身の最後が下のバーの上にある

| 画面 | 横にスクロールしない | 押すところが44px以上 | 下のバーで中身の最後が隠れない | 確かめた日 |
|---|---|---|---|---|
| 取り込み（ファイルを選ぶ・列の対応・確かめ・取り込んだ） | E2E | E2E | E2E | 2026-11-14 |
| 取り込み（同じ人の候補のカード。1組ずつ） | E2E | E2E | E2E | 2026-11-14 |
| 人の一覧 | E2E | E2E | E2E | 2026-11-14 |
| 人のページ | E2E | E2E | E2E | 2026-11-14 |
| 誘う候補（絞り込みを開いたときも） | E2E | E2E | E2E | 2026-11-14 |
| イベントの一覧・イベントのページ・会ごとの声かけの一覧・設定・人を足す | E2E | E2E | E2E | 2026-11-14 |

- 確かめで見つけて直したもの：「人を足す」「イベントを作る」（36px）、人のページの来たイベントのリンク（16px）、同意のスイッチのラベル、下のバーの上の線の1px（中身の最後が1px隠れていた）。
- 確かめのダイアログのボタンは、共通の `ConfirmDialog` で高さ40px（44pxに届かない）。共通の部品なので、直すなら共通の小さな PR に分ける（E2E ではダイアログは開いていない）。
- 実機（iPhone の Safari）での見え方は、T095 の手の確かめのときにあわせて見る。
