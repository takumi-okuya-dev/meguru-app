## 3. スマートフォン（390px幅。T096）

| 画面 | 横にスクロールしない | 押すところが44px以上 | 下のバーで中身の最後が隠れない | 確かめた日 |
|---|---|---|---|---|
| 取り込み（列の対応・同じ人の候補のカード） | | | | |
| 人の一覧 | | | | |
| 人のページ | | | | |
| 誘う候補 | E2Eで確かめた | | | |

- 確かめのダイアログのボタンは、共通の `ConfirmDialog` で高さ40px（44pxに届かない）。共通の部品なので、直すなら共通の小さな PR に分ける。
