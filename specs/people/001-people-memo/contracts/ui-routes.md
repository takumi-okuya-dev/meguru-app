# 画面のルートの取り決め：人物メモ

**対象**：spec User Story 1〜7 | **画面イメージ**：[めぐる 人物メモ モック](https://claude.ai/artifact/Kd69bDnux1dmW1hhkfCum4)（非公開。開けるのはオーナーだけ） | **Webの境界**：docs/module-map.md 7章 | **決めた理由**：[research.md](../research.md) R17・R20

`apps/web/src/apps/people/index.ts`が`AppModule`（`id: "people"`・`basePath: "/people"`・アイコンはlucideの`Contact`・`startPath: "/people/import"`・`withdrawalPreview`）を出し、`app-registry.ts`に1行足す。外枠のほかの場所は直さない。ログインのいらない画面はない。

## 1. 画面（すべてログインが要る・サイドバーの中）

- **サイドバー**（`AppSidebar`。1024px以上と引き出し）：アプリの切り替え／誘う候補／人／取り込み／イベント／下に「誘いの文と目標」（設定）。まだない画面の項目は、そのPRまで出さない。
- **下のバー**（767px以下。R20）：`PeopleShell`が中身の下に固定で出す。誘う候補・人・取り込み・イベントの4つ（アイコンと短い名前）。今いる画面を濃く出す。押すところは44px以上、下の安全な余白（`env(safe-area-inset-bottom)`）をとり、中身の最後が隠れないよう下に余白をとる。アプリの切り替えは上部バーの左のボタンから。
- 人物メモの利用の許可がない人（`/api/me`の`available`に`people`がない）には、`/people/*`を外枠の「使えない」画面にする。APIの403 `APP_NOT_AVAILABLE`も同じ画面にする。

## 2. 取り込みの画面の決まり（US1・US2）

- ファイルは`<input type="file" accept=".csv,text/csv">`で選ぶ。読んだ行はメモリーにだけ置き、ブラウザの保存（`localStorage`など）に書かない。画面を離れたら捨てる（R18）。
- 列の対応は、1列を1行で出す（見出し・最初の3行の値の見本・項目の選択）。覚えた対応・初めから当てた対応には小さな印。LINE名の列が選ばれていなければ「LINE名の列を選んでください」を出して次へ進めない（US1 AS3）。
- 同じ人の候補は1組ずつのカード：左に取り込む行（LINE名・本名・次回参加・欲しいつながり・キャリアの興味）、右に候補の人（同じ項目＋来たイベント3つ・理由「LINE名が同じ」など）。「つなぐ」「別の人」の2つのボタン。候補が2人以上なら、人ごとに「この人につなぐ」。スマートフォンでは上下に積み、1組ずつ進む（Edge Cases「スマートフォンでの取り込み」）。
- 確かめの段で、新しく入る人数・同じ人の候補の組数・取り込めない行の数（理由ごと）・もう取り込んだ行・消した人の行の数を出す（FR-006）。
- 409 `IMPORT_DECISIONS_REQUIRED`が返ったら（プレビューのあとで人が増えたとき）、プレビューを読み直して、決めていない行に戻す。
- 文字が読めない・ZIP・大きすぎるときは、research.md R4の文言を出す。

## 3. 誘う候補の画面の決まり（US3・US6）

- 開いてから1人の文をコピーするまで3回のタップ以内（SC-005）：下のバーで開く（誘う会は初めから選ばれている）→ 行の「文をコピー」。コピーのあと、行に「興味を聞いたにする」を出す（1回のタップで声かけを始める）。
- 「仕事の相談先へのつなぎ」では「文をコピー」の代わりに「声かけを始める」（相談先の名前を入れる）。進み具合のボタンは「OKをもらった」の前に「つないだ」を出さない（FR-023）。
- 同意のない人は、どの絞り込みでも出ない（APIが返さない）。画面の上に「個別の案内に同意した人だけを出しています」を1行。

## 4. 画面の決まり

- 押せるところは、指で押しやすい大きさ（44px以上）。スマートフォン（390px幅）で横にスクロールしない。
- 人を消す確かめは、名前を入れる欄（表示名と同じ文字を入れたら「消す」が押せる。最後はAPIが確かめる）。「元に戻せません」と、消えるもの（回答・メモ・声かけ・別名）と残るもの（会ごとの参加者数）を書く（US7 AS1）。
- 見た目は docs/ui-design.md の今の約束（ChatGPT風・ニュートラルなグレー）と、モックにそろえる。
