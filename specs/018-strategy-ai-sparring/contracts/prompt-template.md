# プロンプトと答えの形：AIと壁打ちして課題を埋める

**Feature**：[spec.md](../spec.md) | **調査**：[research.md](../research.md) R2・R3

014の[prompt-template.md](../../014-strategy-guidance/contracts/prompt-template.md)の2（AIと深掘りする）と同じ書き方。括弧（`{}`）は差し込む値。

## 1. 壁打ちのプロンプト（`buildSparringPrompt(values, targets)`。FR-006）

```text
あなたは、SNS発信の設計を手伝う聞き役です。これから、私のThreadsアカウントの設計のうち、下の{質問の対象の数}項目を、一緒に考えて完成させてください。

■一緒に考える項目
【1】{label}
考えること: {description}
コツ: {tip}
悪い例: {bad}
良い例: {good}
足してみたい観点: {moreを「・」でつなぐ}
こんな場合はどうだろう？: {whatIf}
もっと良くするなら: {better}
今の私の答え: {今の入力 ／ 未入力}

【2】{label}
…(質問の対象の項目ごとに同じ。活動の軸は「考えること」と「今の私の答え」だけ)

■ほかの項目に書いたこと(参考。食い違わないように)
- {項目名}: {入力}
…(質問の対象ではない対象の項目のうち、入力のあるもの。なければこの節ごと入れない)

■進め方
1. 上の項目を順に、一度に1〜2問ずつ質問してください。質問は、答えやすい具体的な問いにしてください。
2. 私の答えにないこと(事実・数字・エピソード)は作らないでください。
3. 今の私の答えがある項目は、その文を生かして足したり直したりしてください。別の内容に書き換えないでください。
4. 項目どうしで、重なりや食い違いがないようにしてください。
5. すべての項目を聞き終えたら、項目ごとの完成版を、下の「完成版の形」で出してください。途中で私が「完成版を出して」と送ったら、その時点までの内容で出してください(材料が足りない項目は、出さなくてかまいません)。

■完成版の形
項目ごとに、始まりの目印の行・完成版・終わりの目印の行の順に書いてください。目印の行は、項目の名前も含めて、そのまま書き写してください。完成版のほかに説明を書くときは、目印の外に書いてください。

【項目：{1つ目の質問の対象のlabel}】
(完成版)
【項目ここまで】

【項目：{2つ目の質問の対象のlabel}】
(完成版)
【項目ここまで】
…(質問の対象の項目ごと)
```

- 質問の対象は`selectSparringTargets`の結果（表示の順）。
- 「発信テーマの掛け合わせ」が質問の対象にあるときは、進め方に「6. 『発信テーマの掛け合わせ』は、候補を3つ以上出し、それぞれの『集まりそうな人』を添えて、私と相談して1つに決めてください」を足す（014 FR-037と同じ考え方）。
- 下書きの4項目と近い人間性は、質問の対象にも文脈にも入れない。
- 長さを削らない（spec Edge Cases）。

## 2. 答えの読み取り（`parseSparringAnswer(text)`。FR-010〜FR-014）

決まりは[research.md](../research.md) R3。例：

| 貼った答え | 結果 |
|---|---|
| `【項目：ターゲットの本音の悩み】`／文／`【項目ここまで】` | `realWorries`＝文 |
| `**【項目：ターゲットの本音の悩み】**`（太字） | 同じ |
| `【項目: ターゲットの 本音の悩み】`（半角の`:`・空白） | 同じ |
| `【項目：「ターゲットの本音の悩み」】`（括弧つき） | 同じ |
| `【項目：Q1】`／文 | `purposeOrigin`＝文 |
| `【項目：A】`／文1／`【項目：B】`／文2（終わりの目印なし） | A＝文1、B＝文2 |
| 最後の項目に終わりの目印がない | 答えの終わりまでがその項目 |
| 同じ項目が2回 | 後のもの |
| `【項目：近い人間性】`／文 | `unknown`＝["近い人間性"] |
| `【項目：好きな食べ物】`／文 | `unknown`＝["好きな食べ物"] |
| 目印の中身が空白だけ | その項目は入れない |
| 目印が1つもない | `markerFound`＝false、`items`は空 |
| 目印の外の文（前置き・まとめ） | 使わない |
