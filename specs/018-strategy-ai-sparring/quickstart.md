# 動作の確かめ方（Quickstart）：AIと壁打ちして課題を埋める

**日付**：2026-11-02 | **計画**：[plan.md](./plan.md)

## 1. 自動テスト

```bash
pnpm --filter ./packages/shared test   # 対象の項目・範囲の絞り込み・プロンプト・答えの読み取り
pnpm --filter ./apps/web test          # 課題の画面の壁打ちの欄
pnpm lint && pnpm -r exec tsc --noEmit
```

確かめること（[contracts/prompt-template.md](./contracts/prompt-template.md)・[contracts/ui-routes.md](./contracts/ui-routes.md)）：

| 場面 | 結果 |
|---|---|
| 空の課題で、範囲がはじめのまま | 「21項目を相談します」。プロンプトに21項目の名前とヒント、「未入力」 |
| 10項目が「十分」で、「未入力と短めだけ」がオン | 残りの項目だけが質問の対象。十分な項目は「ほかの項目に書いたこと」に入る |
| 区分をすべて外す | 「この範囲には、相談する項目がありません」。コピーを押せない |
| プロンプトの中 | 近い人間性・下書きの4項目が入らない。答えの形（`【項目：…】`・`【項目ここまで】`）が入る |
| 21項目の完成版を含む答えを貼る | 21の候補。空だった項目は選ばれている |
| 入力のある項目を含む答え | その項目は選ばれていない。同じ文なら「今と同じ」 |
| 選んで反映する | 選んだ項目だけ置き換わり、未保存になる。保存するまでサーバーは変わらない |
| 目印を太字にした・半角の`:`・「Q1」だけ | 同じ項目として読み取る |
| 目印がない答え | 出し直しの案内。候補は出ない |
| 近い人間性・知らない名前の目印 | 「読み取れなかった項目：…」 |
| 貼った答えがあるまま閉じる | 破棄の確かめ |
| 見せてもらっている人・読むだけ | ボタンが出ない |
| 開閉・コピー・選ぶ | 「AIと壁打ちして埋める」「全体をAIと整理する」の位置が変わらない |

## 2. テスト版で手で確かめる（マージのあと）

実際の外のAIが答えの形を守るかを確かめる。

1. テスト版で、課題がほとんど空のアカウントを開く（なければ新しく作る）。
2. 課題の画面で「AIと壁打ちして埋める」を開き、範囲をはじめのまま「プロンプトをコピーする」を押す。
3. ChatGPTに貼って送り、質問に5〜10問ほど答えてから「完成版を出して」と送る。
4. 出た答えをまるごと貼り、候補が並ぶこと、読み取れなかった項目がないことを確かめる。いくつか選んで反映し、「保存」で残ることを確かめる。
5. 2〜4を、区分を1つだけ選び、Claudeでも行う。
6. スマートフォンで、候補の一覧が読めること、ボタンが動かないことを確かめる。
